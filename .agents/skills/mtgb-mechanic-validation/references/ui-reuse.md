### 牌库顶与结算选择

Discover的InputConfirm沿用原生Cast/Hand（ok/cancel）身份，客户端只翻译按钮和问题。卡图是只读预览，施放与放入手牌通过页脚选项提交；牌前缀揭示使用RevealCards的confirm-cards，双方各自确认。原生免费基础费用不代表追加费用/最低费用被免掉，规则按独立原生断言判断。当前Cast/Hand窗口按本地化问题的实际高度扩展提示及布局，不用缩字适配；查看战场通过CanvasGroup保留窗口并禁用交互，验证alpha/射线/提交守卫，不能断言必须停用GameObject。入口 DiscoverPresentationValidation；三语言/第二席位/再次请求/揭示合同与原失败见 Docs/DiscoverConsumerAudit-2026-10-06.zh-CN.md。任意长牌名、字号与窄屏不由这套样本自动核销。

本项目当前决定：不增加常驻牌库顶卡片，点击牌库区域只读查看收件席位已经知道的当前顶牌；点击玩家手牌数浏览已知手牌，目标／攻击／正在选手牌时让原生选择优先。未知牌库不提供全牌库身份；顶牌改变／洗牌清除记忆，即使洗牌后 ID 相同也不能沿用。手牌私下放回顶牌仅保留拥有者／实际控制者的知识，不能让先前看过对手手牌的席位追踪私下选择。双方私下分别看过同一张牌不自动授权观战者；当前观战投影只保留原生持续公开顶牌。

思绪等实际展示过的手牌保留席位记忆，正常使用／弃掉后移除离手身份，未看过的新抓牌仍隐藏；脑力激荡等私下从手牌放回牌库时清除对手全部旧手牌记忆。不能因为保存了公开信息而把全隐藏区域投影给客户端。用真实思绪→脑力激荡连续流程核对“展示→保留→混入隐藏区后清除”及双方／观战权限；这不证明所有隐藏区域操作都已验证。

少量可选手牌直选不显示中央提示，右下取消／确定；点击牌只保存客户端草稿，确定发送原生 card 选项。超过 10 张改窗口列表，页脚同样取消／确定，已选计数读取本地草稿，选中／取消选中立即刷新；不要伪造引擎 ok 选项，也不改变强制弃牌／多选的原生确认。请求切换、失去操作权限、重复／过期提交分别检查。InputConfirm 不作为手牌直选；只含 Yes/No 且没有牌预览的确认走紧凑单行按钮面板，有牌预览则走卡牌窗口。出现卡牌窗口时隐藏空的 ForgeChoices 及重复右下确认，防止黑条残留。

X 和能量数量复用右下操作位，左侧减号／数字／加号，右侧确定；ChooseNumber 的加减仍发送原生合法 ID，枚举数量只在确认时发送原生选项。保持原生取消入口，不扩大交互权限；所有右下付款／直选／数值消费者检查与阶段、AUTO 的实际矩形不相交。数字点击后等渲染帧，截图值必须与提交值一致。

区域只读列表有牌时不能访问不存在的 Empty 控件。提示从真实完整请求翻译，勘察来源可能含换行。查看战场／返回选择检查字号稳定。工具超时可能重入协程，入口用运行中保护；测试停用联机提示遮罩。扇形手牌用暴露部分的真实射线点击，中心被邻牌盖住不等于整牌无法点击；不能直接调用卡片监听器代替射线。失败驱动与产品缺陷分开记录，不把正确的专用确认面板误认成缺失列表。

OrderCards 按原生目的地和实际移动顺序说明编号；置底时 1 号在该置底牌组的最上面，不能从“Closest to bottom”字面推断相反顺序。排序数字同时检查原 option.order、固定字号、preferredHeight、实际生成字形和截图；N22 的 36px 高标签在 1.3 字号需约 44px，文本字段正确却没有任何可见字形。按实际字体测量扩高并锚定卡图右上内侧，保留原选择编号及提交合同。局部修复只重放两份原排序封包的三语言差异，复用此前类别／落点选择和原付费结果。通知 ID 是各收件视图自己的原生 ID；双方公开结果核对相同 value 与牌 ID，私有重选提示只给实际接收者。依据[本批证据](../../../../.tools/dig-drain-flip-1011/audit.json)。

增量入口 `ResolutionDockPresentationValidation.Run()`；手牌浏览单独用 `KnownHandBrowserPresentationValidation.Run()`（内部转发 RunHandBrowserOnly），检查浏览器开着时记忆清除和牌背→全已知的残留；规则入口 `HiddenZoneMemoryNative.py` 和 `ResolutionReviewNative.py`（可用 MTGB_RESOLUTION_OUTPUT 指定新批次目录），只重跑受影响消费者。旧入口转发到现行检查，旧 `.tools/resolution-ui-1005` 保留历史身份；当前证据见 `Docs/ResolutionDockKnownZoneAudit-2026-10-05.zh-CN.md`。已知顶牌浏览与已知手牌验证不等于完整牌库多位置记忆、全部机制或真实联网通过。

### 插画：比例与构图分别检查

固定 RawImage 的 UV 像素宽高比须等于实际显示边长比。用 TransformVector 计算边长，包含祖先非等比缩放，单纯旋转不改变比例；裁切在 sprite 子区域内，缺图清除旧纹理与 UV，图片不拦截选择射线。

MTGB 的插画从区域最上沿向下等比例裁切、水平居中；牌头保持独立居中策略。现有常规插画范围为 `(0.07,0.43,0.86,0.45)`，UV 原点在左下，顶部为牌高的 88%。首次使用 81% 上沿虽通过比例断言，实际灰棕熊头顶仍被切掉；应与实际加载的本地牌图核对并看真实截图。固定范围不保证异形、全图或特殊卡框都合适，发现差异再按卡框处理。

共用消费者为分配、普通施放／异能选项、异能牌面、备法；模式和已选咒语使用 Header。比例、上沿、最大保留面积与源边界分别断言；再检查真实选项、末对象滚动与查看／返回。备法 payment 重放必须先恢复 ready 和施放点击意图，否则 castingCardId 缺失；这属于驱动遗漏，不能误报为产品缺图。

### 字号：创建瞬间和恢复后都采样

语言切换先断言实际 GamePreferences.Language，再核对至少一个该语言的具体新标签；本项目使用 zh-CN／n-US／ja-JP。传入 n／ja 会回退，文字容纳和非空字形通过也不能算三语言通过。发现别名回退时保留原结果范围，只补实际语言的受影响控件与截图，不重跑原生效果。依据 Docs/AttackBandConsumerAudit-2026-10-08.zh-CN.md。

旧偏好扫描每 0.5 秒才缩放，新文字首帧会先显示原字号；沿用已缩放 fontSize 又可能重复乘比例。文字创建与有意改大小时立即绑定基准，明确标记的图标／数字保留 KeepFont。检查创建同帧、下一帧、跨扫描周期、隐藏与恢复，并按受影响语言／字号组合采样；不只等热身后截图。

Clear 会禁用旧控件并延迟销毁，首帧排除这些旧控件，但仍采样当帧新控件。Unity 对象用 `== null` 识别已销毁／缺失组件，新增绑定不依赖 `??`。字符网格非空不证明字形正确；法术力图标检查准确字体／sprite 与实际画面，`{2}` 等规则符号交给 CardSymbolText。

组件卡面按原模板的实际栏位验收：标题／费用墨迹中心、类型栏、正文边界，以及旅法忠诚费用和传纪章节各自的符号身份、顺序、对应正文。TMP 不溢出仅证明内容容纳，另看实际截图。动态字体先生成字形再量换行；行间交叠用 glyph metrics、baseline 和 scale，字符四边形包含透明 SDF padding。依据 `Docs/ComponentCardRollout-2026-10-08.zh-CN.md` 的栏位纠正；同族代表牌补差异，不重复费用规则或联网回归。

`SymbolizeStackLabel` 保留的禁用 legacy Text 只保存原文。完整高度断言应同时核对实际 TMP 子节点的格式化全文、固定字号及 `GetPreferredValues`，不以禁用 Text 的另一套字体度量代替实际渲染。10 月 5 日日文发掘段落反例：实际 TMP 高 147.7、内容高 153.7，而禁用 Text 报 161.91；旧断言因此误报截断。失败和修正见 `Docs/BattlefieldStressAudit-2026-10-05.zh-CN.md`。
