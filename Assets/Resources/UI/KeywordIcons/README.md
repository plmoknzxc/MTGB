# Keyword icons

Unmodified `sprite_ability.png` from the project's pinned Forge runtime.
`Index.json` uses the matching `FSkinProp.java` top-left pixel coordinates.
The atlas must remain 494 × 740 pixels, without NPOT resizing or lossy compression.
Sprites retain their original colors; a blue rim denotes a gained keyword.
Unsupported keywords and full parameter details remain in the existing inspector.

Source: https://github.com/Card-Forge/forge (GPL-3.0; game artwork belongs to its respective owners).
