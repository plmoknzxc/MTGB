# Local card-template fonts

This directory's font binaries and Unity font-import metadata are local-only and excluded from public Git. Supply fonts with suitable redistribution rights before building a distributable client.

Expected resource names are `NameCN`, `RulesCN`, `NameEN`, `RulesEN`, `StatsEN`. Their local files are not licensed by the project's MIT license. The current local DFWeiBeiGB/DFHeiGB fonts explicitly prohibit giving their files to others; the Beleren/Plantin/other template fonts do not have verified redistribution permission here.

Use licensed replacements under these names, or adapt the card-template font configuration to available open fonts. The independently included Noto CJK fonts under `Assets/Fonts` retain their OFL license.
