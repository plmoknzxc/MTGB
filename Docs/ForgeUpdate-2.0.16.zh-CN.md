# Forge 2.0.16 项目同步记录

2026-11-18 将项目内置 Forge 从 2.0.15 升级到 [Star Trek Release](https://github.com/Card-Forge/forge/releases/tag/forge-2.0.16)，对应提交 `583714b8bfbd9cb04f8bc39ad95861190caf7691`。本次交付范围为项目及 Unity 编辑器，桌面安装包和线上服务器仍是原部署版本。

## 引擎与对局

重新编译 Forge 的 core、game、ai、gui 及 MTGB 桥接，JRE 保持 17。新版把选牌范围、已选对象和可操作牌合并到 Selection，桥接按每次快照替换旧状态。栈目标继续走原生选择窗口。搜牌迁移到共享 ChangeZone 流程，保留 Opposition Agent 对搜索者本人牌库的限制。合并牌的离场排序与新版贴纸保留选择可以共存。

58 个 Java 补丁定义产出 117 个覆盖类，另应用 8 项卡脚本补丁。新版已处理精准磨牌数量、受控投票、迷彩阻挡者筛选和 Stick Together 的队伍归属。两层 GUI 接口核对了 106 和 55 个声明。完整核对了 56,896 个运行文件及文件集合，目录和运行指纹见 `ForgeRuntime/runtime.json`。

## 资料

目录共 99,219 条印刷记录。按系列与编号比较，新增 1,438 个键，修改 158 个，移除 3 个。当前四副本地牌表的印刷键均可唯一解析。搜索、图片来源及风味索引按受影响印刷更新，并重建组牌规则、关联衍生物和 Unity 数据库。日文上游主表合并时保留了两项项目修订。简体中文上游主表与前版相同。同步新增关键字 Prismatic 的中日文说明，关键字词条构建通过。Unity 在中文模式实测 TRK/15 能加载 488 × 680 卡图，牌名和规则因上游缺中文而回退英文。新增印刷补入 1,432 张精确匹配的本地卡面，18 个新增印刷没有匹配的图片；具体键见本地 `.tools/forge-update-2.0.16/art-results.json`。

## 验证范围

- Unity 从新数据库载入 99,219 条印刷，用已保存的 Affinity 牌组启动本地真实 Forge 会话。两席保留起手、私有手牌隔离及进入优先权均通过。
- TRK/15 Emergency Medical Hologram 从手牌施放，平原横置支付，进场异能以自身为目标，结算后获得一个 +1/+1 指示物且生命由 20 变为 21。
- Shock 选定玩家、确认、支付并结算，目标生命由 20 变为 18。修正旧测试反复点击已选目标，以及仍期待 Java 代替客户端让过的假设。
- 三层堆叠、两种触发排序、非法及过期输入拒绝、四组调度、四组受控及普通搜牌、AI 策略 48 项、指挥官及争锋的组牌边界和原生目录加载通过。
- Unity 用新卡库验证了 MTGA Y22–Y26 的导入别名。当前机制覆盖清单已刷新。以上用例的通过范围限于实际执行的断言。新系列全卡效果、贴纸机制完整交互、公网两端对战和新版本发布包仍未验证。

## 秘典宬临时补丁（2026-11-18）

Forge 2.0.16 的系列表收录了秘典宬，但发行版缺少规则脚本。MTGB 的本地补丁以 YSOS/30 提供这张地，沿用 MTGA 导出行 `1 The Mystical Archive (Y26) 30`。法术书的 25 张牌已与[威世智公布的清单](https://magic.wizards.com/en/news/mtg-arena/alchemy-strixhaven-spellbooks)核对。脚本参考 [Forge PR 12525](https://github.com/Card-Forge/forge/pull/12525)，采用本地验证过的放逐关联和支付限制。后续同步遇到同名上游脚本时须重新比对。

运行 `python -X utf8 Tools/ForgeBridge/Test-MysticalArchive.py` 可复现四组真实引擎用例，覆盖进场三选一、对手看不到牌面、支付两点并横置取回原牌、另一块同名地无法取回、产无色，以及混色法术力对起始牌组外的同名实体和起动式异能的支付限制。

Unity 已验证 MTGA 导入、中英文卡名和规则、本地 488 × 680 卡图、法禁标记及对真实三选一请求的渲染和点击。早先的放逐区截图出自旧版战场。验证在本地编辑器和 Forge 进程完成。公网部署、AI 选牌策略、重开对局后的个别交互和法术书中各张咒语的独立结算未在本批复测。

战场沿用 10 月 17 日的叠牌方式。第一张关联放逐牌与来源牌同尺寸、同朝向，垫在来源牌后方并向右下错开。有多张时，第二张垫在第一张下面，只在右下露出少许。两层各自按可见性使用该牌的紧凑战场牌面或牌背。完整列表可在来源牌详情中按权限查看。秘典宬的抽选者能在详情中查到自己选过的「倨傲击」，对手只能查到面朝下的牌，观战投影也会移除私有牌名和印刷信息。取回该牌后下叠牌消失。

短时封锁的本地测试覆盖一张、两张和五张实体牌。两张的场面中，Forge 按顺序关联了灰棕熊和愤怒鬼怪。Unity 新旧战场均使用灰棕熊的牌面压住愤怒鬼怪，只有一张时只显示灰棕熊。短时封锁离场后实体牌回到战场，已消失的衍生物不会留下条目。

## 星际迷航中文和特殊牌验证（2026-11-20）

TRK 的 311 个规则牌名和 TRC 的 337 个规则牌名均已具备中文牌名、类别和对应的规则文字。本次补入 356 条，另外修正既有译文。Unity 中文环境逐一读取两个系列的 1,143 条印刷记录，并对五条原生 Forge 路径中的 28 个对战画面检查了界面文字。

大学院废墟已发布、能与本地印刷对应的中文整图共 630 张，其中 TRK 306 张、TRC 324 张。用 `python Tools/ForgeBridge/Import-ChineseCardImages.py --sets TRK TRC` 可重新检查这两个系列。首次导入后的全部 JPEG 均通过解码、尺寸及哈希核对。加上能采用既有同名中文印刷的五种基本地，648 个规则牌名中有 635 个可显示中文整图。Unity 中 TRK/165 和异画 TRK/383 均能加载 TRK/165 中文版。TRC/187 的大学院废墟条目提供中文卡文，整图仍为英文。TRC/131 在本地没有整图；该系列共有 13 个规则牌名缺少大学院废墟的中文整图。

原生对局测试入口为 `python Tools/ForgeBridge/Test-StarTrekQ.py`，需要本项目的 ForgeRuntime 和 Java 17 编译器。其中两例核对暗中做牌的Q放逐手牌支付起动费用、支付法术力施放复制品，以及原牌留在放逐区。其余三例核对您显赫的东道主Q横置三个不同仙灵后免费施放翻出的非地牌、Q连续体使目标得 +1/+1 和警戒，以及博格女王同化后的操控权、类别、指示物和攻防。Unity 使用真实 Forge 请求验证了选择仙灵的中文提示和点击。尚未逐牌执行这 648 种牌的所有异能与选择分支。
