# 新场景：重复地叠放与产费色边框

仅 `IntegratedBattlefieldRedesign` 的标记启用新展示；原战场场景文件未改。未打包、覆盖客户端、部署服务器或上传 Git。

## 行为

- 相同状态、相同功能的重复非生物地合成一个位置，保留数量角标，并画出后方卡片边缘。不同印次／异画可以同组，实际名称／规则／状态仍须一致。
- 横置与未横置、指示物、召唤失调／属性变化等继续区分。贴附、记忆／压印／放逐关联、复制／特殊选择等沿用权威的保守保护；本回合／本局只有不受次数限制的普通产费激活时，可以继续叠放。
- 当前权威选项的可用／禁用／待检查／已选状态不同则分开；正在被堆叠指目标的地单独展示。个体选择请求暴露对应实际牌。单击组先展开，不代为提交；再选一张才提交其准确原生 ID。
- 产费色框按 Forge 当前异能的 `getProducibleColors()` 投影：无有色产费为灰，单色为对应色，双色为左右两色，三色及以上为金；无色不额外算一种有色。不是按地牌自身颜色或费用判断。可用的地保留独立细青色外轮廓，选中状态保留原高亮。
- 边框复用原圆角素材，双色在 UI 顶点上着色，没有引入低分辨率图片。叠放边缘参与密集牌区的既有边界测量。
- 旧记录没有新增字段时，只用公开基本地类别／明确产费字样作颜色回退，不猜不明颜色；不绕过缺失的安全合并证据。完整新叠放须随下一包同步新的桥接字段。

## 接入

新增可选字段 `landPresentationKnown`／`landStackable`／`landManaColors`，只从公开战场地导出。原 `stackablePermanent` 判定保持不变。新场景单独使用归一化组键，同步用于普通／密集排列、移区及翻面定位；默认公共组键入口和原场景仍走旧分支。

候选桥接在 `.tools/redesign-lands-1026/classes`，未覆盖安装运行时。覆盖清单只刷新分类，没有运行全量效果或恢复暂停的机制目标。

## 证据

- `.tools/redesign-lands-1026/result.json`：24 项通过。真实原生优先权中激活两张 Hallowed Fountain 产生两点蓝费，核对使用后的安全叠放字段；真实施放 Blood Moon、再用 Disenchant 消灭，产费色随原生静态效应变红／恢复。灰、蓝、双色、多色及不能直接产费的找地地分别投影；带记忆的初始地夹具不得合并。
- 首轮未安排白色来源导致驱动试选不可用 Disenchant，保留 `result-round1-fixture-white-source.json`；补 Plains 后旧断言又误把基本 Plains 当非基本地，保留 round2。修正夹具／断言后完成；未据此修改游戏规则。
- `design-demos/battlefield-redesign-2026-10-24/land-stacks-ui.json`：131 项通过。实际 `zh-CN`／`en-US`／`ja-JP`、三窗口及大字号；组数／物理总数、叠放边缘、四类色框、玩家／法术力避让、射线展开且不提交、选择具体原生 ID、横置重组、关联／指示物／目标分开、异画同组、个体选择及原配置隔离。
- UI 原生请求回放将宿主独立的 `request` 按接收者合入 `views[0]`。首轮只读 views 造成提交断言失败，以及预览中中英文状态不同的两张 Hedge Maze 未合并，保留 `land-stacks-ui-round1.json`；修正驱动与预览组合，不放宽真实状态匹配。
- 场景预览保留已有战场，新增灰框／金框例子；新增权限字段取上述真实原生地的投影。预览的跨座位复制、异画／指示物／目标压力组合是 UI 适配器，不冒充同一局或新卡牌效果证明。
