# 通用选牌、刺探与排序

## 接入范围

- Forge `many`、`chooseSingleEntityForEffect`、`chooseEntitiesForEffect`、卡牌 `order`、`reveal` 和 `manipulateCardList` 接口。
- `InputSelectEntitiesFromList` 与牌库、指挥官区、备牌候选投影；手牌、战场、坟墓场、放逐区沿用引擎合法选项。
- 刺探与占卜分别返回牌库顶/坟墓场、牌库顶/牌库底的有序列表。
- 单选、多选、重选、数量范围、排序序号、只读展示、引擎允许时的取消/空选。客户端不自行修改区域或判定合法性。

选牌请求附带授权候选的卡图信息，只投递给当前请求席位；未获准查看的牌以牌背表示。整个未知牌库不会作为通用排序窗口的背景列表下发。异常仍明确终止并报错，不再无限显示等待对手。

## UI

2026-09-25 更新：普通选牌直接点击卡图，卡下不再显示“可选”“已选”“不可选”等状态文字。合法候选排在前面，保持正常亮度；引擎允许查看但不满足检索条件的牌排在后面、变暗且没有提交入口。选中使用金色边框。占卜/刺探保留置顶/置底/入墓操作和去向，排序序号显示在卡图角落。

普通列表选牌点已选牌会取消；最大数量为一时，点另一张会替换原选择；多选满额时不会替换已有选择。选满后仍可调整，点底部确认才继续结算。桥接调用 Forge 自身的选择方法与确认合法性校验，跳过桌面版选满即提交的 refresh。单目标施法请求暂存选择，确认时才交给 Forge 原始目标处理流程。

检索时非候选牌只在 Forge 已授予当前席位逐卡查看权限时显示。Cultivate 实测非地可见、不可选，伪造选择也被服务器拒绝；Impulse 实测只显示获准查看的顶四张，不扩展至全牌库。

Merfolk Branchwalker 的探险已验证三个分支：翻到地进手牌且无额外指示物；非地入墓并增加 +1/+1；非地留顶并增加 +1/+1。确认提示现在同时显示被翻开的卡图。

统一卡图窗口支持点击卡图或选择按钮，显示已选状态、序号和数量要求。大量候选分页并可滚动；少量候选用较小窗口。占卜/刺探显示置顶、置底/入墓，已分配的卡显示去向。提交后锁定按钮，等待服务器发来下一请求。堆叠目标继续使用原先可点击的堆叠卡牌。

`Test-Scry.py` 和 `Test-StackInteractions.py` 回归通过。运行资源清单与打包桥接源码已同步。
