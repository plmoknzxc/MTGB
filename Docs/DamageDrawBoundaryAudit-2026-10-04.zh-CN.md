# 伤害、预防与抓牌替代边界复核

本轮从共用的替代排序、可选确认、来源选牌、私人看牌和状态展示继续补验。原生 Forge 决定候选、操作玩家、费用及结果；桥接传递准确编号与上下文，Unity 提交原生选项。没有以加载、提示词或截图代替实际结算。

## 桥接与共用展示修正

1. 原生可选替代的长英文问题在旧界面截断，并有重复确认入口。增加作用域内的原生来源／替代效果／受影响对象；复用替代牌面，明确接受与拒绝，并关闭重复的通用选择／确认面板。
2. 原生 ChooseSource 候选含负编号的分组标题卡。仅在准确的 ChooseSource API 上过滤这些原生标题，保留实际候选对象与顺序。其他选牌不按卡名猜测来源。
3. 来源选择标题和说明立即应用当前字号。验证发现后续通用设置又开启自动缩字号，已修正覆盖顺序。
4. 已知原生发掘描述仅在名称、数量与未改变的印刷规则段落准确匹配时使用现有译文；未知、动态或不匹配文本保持原生。没有宣称所有卡文／卡图语言已完整。

可选替代受影响对象的玩家分支已验证；受影响牌的字段只发送本操作玩家有权看见的牌，该分支本轮未实测。
