# 战场、语言与 BO3 换备增量修复（2026-10-14）

本批只处理用户最新截图及其共用交互链路。未打完整客户端／服务端包，未覆盖桌面客户端，未部署服务器；仅编译诊断用脚本程序集并在隔离的上一轮程序底座运行。长期机制 goal 状态、原批次身份和核销数字未改。

## 修复与原因

- **已有中文规则的显示绑定**：原始状态详情、动态地规则和异能比较均接入已存在的印刷规则翻译。处理原生英文段落和中文资料不同的换行／句子拆分、去掉前导格式符，以及替代费用提醒重新拼接；相同规则按语言版本缓存。生成的检视／下回合抓牌逐段翻译，保留实际玩家与目标。未编辑卡牌资料或翻译表，不把不匹配的金额替换成固定费用。
- **单张选择**：玩家选满一张后，消费原生已启用的 OK，不再展示第二个确认／重新选择窗口。可选的一张在选中后同样完成；空选择和多选仍保留原合同。数据取自用户实际否认之力请求 805，Unity 回调消费和防止重复提交分别检查。
- **阶段与悬停**：阶段条只在主阶段类别／回合变化时启动过渡，减短等待，移除每次场面刷新强制同步 Canvas 布局；悬停详情延迟 0.75 秒，退出／拖曳取消待显示的详情。没有新增开局准备遮罩。
- **战场空间与合并**：缩小基础场上卡，保留稀疏场面较大尺寸；生物／地及双方保持间距。行数预测现在复用实际展开／不可合并状态的分组，而不是只数原始相同键；最多六列，溢出维持两行横向分页。没有独立关联状态的相同非生物衍生物忽略生成来源进行视觉合并，横置、指示物、关联、当前规则和卡图区别仍保留。食物用两种生成来源的真实 Forge 元数据核对。
- **单张刺探／占卜的按钮**：根据实际卡图底部定位按钮，缓存更新也采用相同算法；默认字号和最大字号 1.3 均检查。
- **换备与第二局**：直接在当前战场打开换备面板；第二局重新加载战场清空上一局的交互状态。更新已有卡牌节点和数量，不整栏重建；复用另一栏或本局已显示的对应语言卡图。双方就绪后房主自动请求下一局，仅用于局间换备。共享目录精确印刷查询建索引，仍拒绝歧义印刷。
- **卡图重复查询**：同一帧内同印刷／牌面／语言／偏好只做一次版本搜索；后续帧仍会重新发现卡图，复用时检查文件改动。修复了七张相同手牌重复遍历大量基础地印刷导致的停顿。
- **录像与资源压力**：编码直接把 JSON 写入压缩流，避免整份 JSON 字符串及 UTF-8 副本并存。接收后在工作线程流式检查头信息、时间轴、席位、JSON 结构和大小上限，保存收到的原始压缩字节；保存不需要展开所有卡牌对象。完整 DTO 绑定仍在播放 Decode 中执行。不保存的录像直接丢弃；接收超时与结果界面生命周期分开，断开连接后的旧解码不会弹出新提示。选择保存后即可换备，无须等待传输或磁盘保存。

## 实际验证

- **29 项 Unity 消费者／显示检查**：原始／动态地中文、米斯拉的饰品检视与延迟抓牌、否认之力提醒拼接、完成选择的实际 OK 回调及防止重复提交、单张可选合同、录像超时、刺探按钮、悬停、食物分组、阶段条，以及双方各 6／10／18 个生物的布局边界。最终生物／地间距约 56–79 个 Canvas 像素；截图人工检查完成。
- **25 项原输入语言回归**：沿用旧原生数据，检查共用展示消费者，包含横置图示、异能／施放方式和变化费用不被误替换。不是新增 25 场规则效果验证。
- **8 项录像检查**：中文名字、尾随 JSON／席位错误／缺失玩家结构拒绝、压缩与展开大小上限、用户真实 428 帧旧录像的头和时间轴相等、保存字节不变。摘要校验在此机器工作线程约 1.22 秒；完整旧录像流式往返检查也通过。该旧录像解压约 70.5 MiB。
- **最终真实本机服务端＋两个客户端 BO3**：不同主／备牌，第一局原生结束，录像尚未收完即进入换备，实际移动卡牌和点击就绪按钮，第二局双方保留起手并开始回合。移牌合计约 2.37／2.42 ms；进入换备约 618／66 ms；局后最大帧停顿约 1.18／0.58 秒，相比同机前序 4.95–5.06 秒明显减少。两客户端均 PASS，没有被强制退出。隔离服务端由测试编排器结束，其 Windows 退出码 1 不代表自然崩溃。

## 证据口径与限制

- 本机双开使用真实传输和 Forge，但没有把本批源码部署到阿里云验证；下次发布需同步服务器的流式录像编码优化。
- 大录像传输夹具把已有真实 428 帧放入本次已结束对局，是传输／保存压力测试，不是新执行 428 个卡牌效果。食物夹具是原生元数据适配，未重施放生成牌；否认之力采用实际请求及 Unity 消费者，未重新验证其引擎规则效果。
- 无图形诊断循环的帧耗时不等于 GPU 60fps 证明。冷面板构建／第二局载入仍有上述约 0.6–1.2 秒的停顿，不能声称所有机器都完全无卡顿。
- 语言检查覆盖已知中文资料的上述共用入口，不能据此声称所有未知生成句子都有完整翻译。
- 图工具 index_status、search_graph、check_index_coverage 均报 Transport closed，使用准确源码回退，未作全项目穷尽结论。
- 保留失败夹具记录：场景切换丢失探针、原生保留手牌选项名差异、第二局重用请求号、无请求却声明等待输入，以及 Editor 重载中断工作线程；修复驱动后仅重试对应路径。布局边界检查确实发现并修复两行生物挤地和不安全分组行数预测错误。
- 已刷新 MechanicCoverage 分类清单；分类与哈希过期标记不等于新增待执行效果，也没有因此续跑全机制测试或修改 goal 数字。
