# 选择窗口与查看战场复核

## 改动

普通、固定数量的模式咒语在 Forge 开始宣布前先选择可取消的施放意图。后续原生 Charm 回调消费准确的原始模式身份；若宣布后的候选或数量改变，则重新进入原生强制选择。不会向强制触发／结算回调塞入非法的取消响应。动态数量、重复模式、随机、其他玩家选择、爪印、可选原生确认等仍保留原生流程，本轮没有证明这些分支都有施放前取消。

选项牌面只采样原卡图上半部，下半部用深色卡框、内嵌圆角纸面和固定字号规则文本，避免矩形完全盖到卡牌边缘。长文本仍可滚动，禁用状态保持不透明。

共用“查看战场”控制处理模式／费用／数值／牌名／其他对象选择、选牌和两堆列表、占卜、地城、异能／替代排序、伤害分配、调度、结果通知／记录以及结局窗口。查看时用 CanvasGroup 隐藏并取消窗口及遮罩的射线拦截，窗口仍保持活动；“返回选择”在设置旁。所有原生提交与 AUTO 暂停，已选项、输入、分页和滚动不因查看而重建。相同原生 context 的更新继续隐藏；新决定、席位／对局身份变化或空状态自动恢复。通知计时在查看期间暂停。

## 实际规则证据

固定 Forge：`4ec5f1a2c32fa90ecb983a72b9eb47aa5c5d7676`。本轮包清单：`c449df4b9630d52d4938ab6462844a8a1b59a3993999439e8bcb4e4fc5e900c5`。

- `choose-one`：真实施放波洛斯护符，选择一项、支付两点、准确玩家目标、四点伤害及恢复优先权。
- `choose-one-cancel`：零选择时有取消，选一项后仍可取消；取消后牌在手里、地未横置、双方生命未变、堆叠为空且恢复优先权。
- 四项追欢相关回归：三项足额组合；组合费用不足时禁用和非法响应拒绝；前两项没有目标时准确原始第三项；没有可支付额外项时不能确认且取消恢复。
- `FraMechanics/modal`：真实施放 Craftwork Crusher、支付、选择两项并结算出衍生物／抓牌，30 步通过。其进战场模式请求仍强制完成，没有假造取消。

原生驱动、每项结果和 SHA-256 在 `Tools/Validation/Reports/ModeChoices/`，FRA 在 `Tools/Validation/Reports/FraMechanics/modal*`。六个模式场景来自两次驱动：先运行六项，再只增强／复跑取消后的资源断言。不同驱动版本归档并匹配结果元数据，不能把最新 `result.txt` 的单项结果当六项整批结果。

## Unity 证据

`BattlefieldViewPresentationValidation` 的主套：中文重放 15 类实际原生请求，英文／日文各复核模式、选牌、牌名；合计 21 个隐藏／返回场景。实际射线点查看与返回，检查所有活动窗口／遮罩不显示也不拦截、保留滚动／输入、隐藏期间不能提交、返回后准确编号／旧请求／重复／非操作客户端拦截。连续的真实模式快照验证相同 context 和新 context 的差别。通知、记录与调度另外是 UI 适配器夹具，不能算规则效果通过。输出 `.tools/battlefield-view-review-1004/`，65 张截图。

结局窗口通过 `RunResultWindowOnly()` 的高 sortingOrder UI 夹具单列验证；不是实际结束对局、保存录像或网络生命周期证明。主套的结果字符串仍保留其当时“结局窗口只读源码核对”的范围，适配器结果另存 `end-result-adapter.txt`，不改写前一批次。

`ModeCardPresentationValidation` 本轮重放三语言的 11 个普通、追欢、增幅、呼魂和进战场多选输入，合计 33 张截图。验证规则区域采样／不透明、内嵌卡框、固定字号、长文滚动、原始规则行、数量门槛、禁用和点击权限。费用／呼魂原生效果沿用前一轮同分支历史证据，本轮没有重跑这些不受影响的规则。

界面重放不等于完整实时对局。`real-stack.json` 从本轮真实波洛斯护符轨迹中提取已施放后的优先权快照：右侧确有原生堆叠。模式意图请求发生在入堆叠之前，所以模式截图里没有该咒语堆叠项是符合当前原生时机的；不为截图伪造堆叠。

## 失败、限制与回归范围

首次隐藏测试发现 Unity 的缺失组件对象不能用 C# `??` 判空，导致 CanvasGroup 没有创建；改用 Unity `== null` 后复核通过。失败保留在 `.tools/battlefield-view-attempt-1/`。较早按钮位置挡住手牌，位置修改后只重新跑受影响的隐藏／返回套，原结果保留在 `.tools/battlefield-view-position-attempt-1/`；没有重新跑无关规则。

结局夹具首次因测试入口重复启动而互相覆盖窗口引用，错误保留为 `end-result-adapter-double-start.txt`；测试入口加防重入后单独通过。主套后补对局身份和 AUTO 保护，结局适配器在最终源码运行；没有借此声明真实联机 AUTO、换局／结束保存流程已实测。

图工具 `list_projects` 与 `check_index_coverage` 均 Transport closed；使用准确控制器分部、编辑器验证和桥接源码回退，原生 Charm 合同另读本地固定 Forge 源码并核对运行类。没有图完整性结论。完整网络时序、所有机制组合、所有特殊模式取消、不同分辨率／其他设备和完整动画仍未验证。总 goal 保持暂停；清单刷新不是全卡池效果通过。
