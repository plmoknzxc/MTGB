# 边界响应测试卡

> 后续更新（2026-09-05）：本文保留当时的审计/导入记录。制卡基础现已升级 schema v8，Lua 嵌套回调与多库身份、内容分类已修复，最新状态见 [制卡基础验收](AuthoringFoundation.zh-CN.md)。
本组为 DIY 测试牌，不是官方卡牌实现。全部使用 Data Editor schema v7、Lua API v2。
数据库保留原有卡牌；新增 TST/10–13。牌组编辑与联机准备页可选择“边界响应测试”（60 张）。

额外费用、替代效应、持续效果叠加、历险和传纪的新测试卡见 [专项机制测试](SpecialistBoundaryCards.zh-CN.md)；选择牌组“专项机制测试”。

| 编号 / 名称 | 费用与效果 | 重点边界 |
|---|---|---|
| TST/10 回溯脉冲 | `{U}` 瞬间；目标生物回其拥有者手上 | 对手回合响应；目标离场再进场后不是原对象；拥有者与操控者区分 |
| TST/11 堆叠截断 | `{U}{U}` 瞬间；反击目标咒语 | 空堆叠不能施放；不能选启动/触发式异能；被反击的咒语不能继续结算 |
| TST/12 双生增幅 | `{G}` 瞬间；至多两个目标生物各 +1/+1 至回合结束 | 0/1/2 个不同目标；禁止第三个；部分目标失效仍结算剩余；全部失效不结算；回合末移除加成 |
| TST/13 可控放电 | `{X}{R}` 瞬间；目标玩家受到 X 点伤害，X 最大 10 | X=0 合法且仍需支付 R；可支付上限；禁止超额 X；声明锁定后正确扣费和结算 |

X≤10 是这张测试牌的明确规则，不是对所有 X 咒语的通用限制。

## 双开操作清单

### 连续对局回归（第一阶段补充）

`MTGB/Validate Boundary Match Flow`（也纳入全项目验证）在停止 Play Mode 时运行。
当前会分别对 `BoundaryResponses.mdk` 和 `BoundarySpecialists.mdk` 执行下列 16 局流程，共 32 局；下方旧统计是引入专项牌组前的记录。
测试从真实的 60 张边界牌组洗牌、双方各调度一次和置底开始，只通过
`GameRules.ApplyAction` 提交正式动作，不直接修改阶段、堆叠或手牌。

- 固定种子 7241–7256，交替先手，覆盖双方自动/全控；每局推进至第 13 回合或规则判定结束。
- 前八局不宣告攻击，后八局选择合法攻击者/阻挡者；不能在 1600 步内推进则失败。
- 每步对双方视图做 JSON 往返和客户端应用，比较阶段、优先权、手牌数、堆叠数、可出牌和产费能力标志。
- 拒绝过期状态序号的请求；非持有者不能让过优先权；被拒绝的请求不能修改状态。
- 每局完整重放所有已接受动作，逐步验证状态哈希并比较最终哈希。

这是固定策略的规则层回归，不是穷举：数字选择默认取最小值，可选目标允许零个；
非零 X、部分/全部目标失效等仍由单卡边界套件覆盖。此测试不发送网络包、不操作 UI，
不能据此宣布真实双开、鼠标高亮/拖曳、掉线重连、BO3 换备或所有卡牌组合已通过。

测试显式隔离全局 GameEvents 并清理 GameRules：Edit Mode 销毁组件不会可靠执行运行期生命周期清理。
首轮发现已销毁的测试 GameRules 仍订阅 OnCardPlayed，导致效果重复；该轮统计作废，不能把回放一致当作规则正确。
新回归要求每局只存在一个卡牌使用监听器，清理后为零，再恢复进入测试前的事件环境。
2026-09-04 隔离后重跑通过：16 局、2976 个已接受动作、328 次手牌使用入口、
15 次攻击者选择、2 次阻挡宣告；15 局到达第 13 回合，1 局在第 11 回合结束，全部回放一致。
随后全项目自动检查通过。阻挡样本仍很少，不能视为复杂战斗覆盖充分。
本次双开启动在 Multiplayer Play Mode 执行图处出现 `TaskCanceledException`，没有完成真实双客户端验收。

### 实机验收

双方选择“边界响应测试”，需要稳定停留窗口时双方开启全控。

1. P1 施放双生增幅选两个生物；P2 用回溯脉冲移回其中一个。仅仍在场的生物应获得加成。
2. 以一个生物为目标施放回溯脉冲；响应中使该生物离场再进场。原咒语不能追踪新对象。
3. P1 施放预视；P2 用堆叠截断反击。P1 不得抓牌，两张咒语最终进入各自拥有者的坟墓场。
4. 场上没有生物时，双生增幅仍可选零目标施放；回溯脉冲不可施放。
5. 有 R 和三个其他法术力时，可控放电只允许 X=0…3；选 3 后总共支付四点法术力，目标玩家失去 3 点生命。
6. 对照两端：选择期间只有选择者可操作；公开堆叠、生命与区域变化一致，对手手牌不泄露。
