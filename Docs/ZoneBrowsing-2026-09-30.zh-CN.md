# 战场区域牌堆与查看列表

## 行为

- 采用用户选择的“与头像合成一块”版本：姓名、生命值和三个区域入口共用底板，区域栏在下方，用矢量图标和名称替代三个缩略牌堆。
- 自己的徽记和延迟效果在玩家面板上方，对手的在对手面板下方。放大到 120×82，每行两个；堆叠整体下移，并随对手标记换行避让。
- 悬停牌堆时，下方仅显示数字张数；移开后隐藏，并带轻微缩放过渡。
- 点击墓地、放逐区，复用找牌界面的卡图列表、分页和大图详情；同名牌按独立对象分别保留。
- 列表打开期间收到普通对局更新会保留查看状态、刷新牌的内容。引擎要求选择卡牌时恢复引擎选择界面。
- 对局中不下发完整牌库，点击牌库只显示张数和非公开信息说明。本局结束后，参与者能查看自己剩余牌库，对手和观战者不能查看。
- 放逐区中有查看权限的面朝下牌通过授权字段展示；观战者投影会移除这些字段。
- 卡图全部读取本地资源，缺失时显示缺失卡图，不临时联网取图。

## 验证

`python -X utf8 Tools/ForgeBridge/Test-ZoneBrowsing.py`：PASS。

真实 Forge 场景分别给双方放入两个同名灰棕熊、一个闪电击，以及一张公开和一张面朝下放逐牌；检查两席的墓地对象 ID、印刷图号、放逐张数、面朝下牌无公开图号，以及对手手牌和整个牌库没有泄露。

Unity 运行界面通过按钮与悬停事件回调验证：悬停只出现数字、点击墓地/放逐区打开卡图列表及详情、12 张牌翻到第二页显示剩余 2 张、普通状态更新保持列表打开、拥有者剩余牌库可查看而对手牌库隐藏。结束后剩余牌库 UI 权限使用带 `reviewLibrary` 的验证快照检查；没有在此验证中完整打一场对局。
