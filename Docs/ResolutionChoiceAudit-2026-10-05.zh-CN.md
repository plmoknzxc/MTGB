# 牌库顶、单项确认与四张咒语结算

## 改动与依据

用户截图中的红圈是被确认窗口遮住的来源生物 Merfolk Branchwalker，并非牌库顶。勘察确认针对预览中的揭示牌。

- 两侧头像旁加入牌库牌面：未知时显示牌背，知情席位直接显示当前顶牌。实际揭示记录与原生可见权限按席位保存；手牌放回的已知顶牌也保留。顶牌改变、移出或洗牌清除记忆，客户端不保存上一请求的私有预览。
- 只读牌库列表最多补充已知顶牌，其他牌与顺序仍隐藏。修复有牌列表不存在 Empty 标签时的空引用。
- 烫血地等双答案确认按文字实际高度收紧，左右各一个按钮。取消／自动支付横排，各占右下推进按钮约半宽，保留阶段短条；撤回 Z 移到回合文字上方。
- 成长涡旋直接选手牌时，取消移到右下，删除只装一个取消按钮的巨大中央面板；同一共用入口处理授权手牌展示确认与弃牌。多手牌仍回退列表。
- 四张咒语的已识别提示采用现有中／日牌名和本地交互文案，固定字号；原生费用、候选和是否可取消不靠翻译判断。

坟墓场、放逐区仍沿用现有区域入口与只读列表；本轮未增加三区域完整卡片移动动画或完整物理牌堆。

另有 **1 个适配器检查**：实际勘察保留后调用生产洗牌事件处理器，在牌库顺序未改变、顶牌 ID 完全相同时清除知识；这不冒充实际洗牌咒语效果验证。

## Unity 与证据

- `ResolutionPresentationValidation.Run()`：重放上述真实请求，三语言射线点击对应牌号／确认／取消；私有顶牌不传对手或观战者；只读浏览不提交；顶牌移走清除图片；查看战场／返回保持字号；真实带 Undo 的优先权请求核对撤回位置。授权手牌展示、思绪弃置和自己的弃牌作为共用入口消费者单独采样，不重复其规则首验。
- `PaymentDockPresentationValidation.Run()`：三语言原生烫血地／Mana Leak 请求重放、横排按钮矩形及点击、不足费用、旧／重复／非操作／提交中保护、自动控制付款边界。此前原生6个付款规则场景保持原批次身份，本轮排版变化不重做付款结算。
- 原始资料、截图、结果和失败位于 `.tools/resolution-ui-1005/`。最终聚合使用 `ResolutionReviewProof.py`，记录文件哈希及独立 UI／规则身份。
- 新桥接类及运行包清单哈希已增量更新；只核对桥接类和清单自身，不宣称重新哈希整个运行包素材。

普通 X 咒语此前被强制使用未本地化的 prepared 牌面；改为复用选定咒语牌面显示 X 值、本地规则与能量图标，PreparedSpell／Secondary 的专用路径保留。能量选择截图等待数值刷新到3后再保存；通用搜索确认的地牌措辞仅在对应 Growth Spiral／Planar Genesis 堆叠源存在时使用。

能量 `{E}` 原本未在 CardSymbolText 登记，添加现有玩家指示物图集的 TMP fallback sprite，未加入法术力池；规则文字中直接使用同源图标。补采样已有 Walking Ballista X=2 原生堆叠消费者，并断言能量与通用费用均生成 TMP sprite 网格，能量材质取玩家指示物图集；结果为 x-symbol-delta.txt。检查渲染网格与截图，不能只检查字符串替换。

最终截图复核发现真实勘察提示包含来源牌名换行前缀，原本只匹配整串开头的翻译未生效；改为匹配独立 Explore 行，单独三语言提示／恢复字号／确认 ID 检查，结果 explore-prompt-delta.txt，不重做其他结算。增量首张截图只等帧未等翻译就绪，牌名仍英文；改为等待 locale revision／Ready 并断言牌名已翻译后再截图。

## 失败与限制

原始驱动尝试保留在 native/attempts：最初漏掉 InputSelectEntitiesFromList、揭示确认用错 ID、排序用错 ID、数字范围当成枚举；均修正驱动，不修改原生结果。旅法夹具未初始化忠诚造成施放前离场，修正起始状态后才验证天空之怒。

UI 最初多次执行／超时后的并行协程互相覆盖测试输入，记录保留为 `ui-attempt-*.txt`；增加运行中防重入，并退出运行重新开始。只有独立完成的最终结果作为有效 UI 证据。测试期间停用编辑器联机提示遮罩，避免其 OnGUI 干扰；这不是卡牌效果修改。

观战者当前只获得原生持续公开权限的顶牌；揭示结束后的公共记忆不提升为观战权限，分别私下看过同一牌也不算公开。完整观战揭示记忆、其他隐藏区域流程、无候选／替代效果组合、全牌库排序、多玩家／实时网络和区域移动动画未包含。长期 goal 保持暂停，不把这些有限场景说成全卡池验证完成。
