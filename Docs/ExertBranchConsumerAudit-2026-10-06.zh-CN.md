# 耗竭（Exert）费用、攻击选择与重置状态

本批只核对 R50 原行：实际费用／攻击声明、跳过下一次重置并恢复、原生状态显示。六场规则验证、三语言完整界面验证及双攻击者定向界面补验均已完成；R50原行保存原生／UI／审计哈希后关闭。代表样本不表示每张耗竭卡所有效果通过。

## 实际原生操作

| 场景 | 操作与结果 |
|---|---|
| attack-exert | Glory-Bound Initiate实际攻击，选择耗竭、重置选择再选择确认；获得 +1/+3 和系命，造成4点伤害并获得4点生命；下一次己方重置保持横置，随后一次恢复 |
| attack-decline | 实际攻击但不选耗竭而确认；造成3点伤害，不获得系命／生命，下一次己方重置正常重置 |
| attack-two | 两个同名但不同 ID 的攻击者分别声明、同时耗竭、重选；总计8点伤害和8点生命。两个原生对象的待重置席位及本回合耗竭次数分别核对；回合结束增益消失但待重置状态保留，下一次均保持横置，随后均恢复 |
| mana-exert | 绿洲仪式师选择横置且耗竭的实际产费异能，池增加同色两点；下一次己方重置跳过，随后恢复 |
| mana-ordinary | 同一来源选择普通横置产费，池增加一点，不产生耗竭状态，下一次正常重置 |
| mana-cancel | 从真实异能菜单取消，回到优先权；来源未横置、未耗竭、池未增加 |

夹具只摆放初始卡牌并去除召唤失调。ExertBranchFixture 只读原生 `getExertedThisTurn`、`isExertedBy` 和横置值；没有调用 `exert`、修改攻防或人为推进重置结果。实际操作、支付／选择、伤害、生命、到期和重置均由 Forge 产生。

原生结果：`.tools/exert-branches-1006/native/results.json`。每次尝试保存独立目录、原始请求／视图、只读观察和生产者哈希；历史尝试不当作新的首验数量。

## 发现与修复

- 卡牌协议原来没有耗竭状态。现在只在战场对象上投影原生本回合耗竭次数与待重置玩家席位；不能用“本回合耗竭过”代替跨回合的下一次重置义务。
- 原生攻击耗竭调用返回 OrderCards，但语义是可选攻击者集合。已知固定原文单独标为 `exertAttack`，共用选牌／重选／确认；显示“耗竭”而非排序，不添加顺序数字。零选择确认表示拒绝耗竭。
- 战场小标记和详情蓝色状态引用待重置席位，原始状态不含该标记；分组键保留这些原生值，状态不同的对象不会错误合并。暗置观战投影保留公开耗竭状态，不增加原牌身份。
- 中文沿用固定项目卡文的“耗竭”；初版误用“督战”的截图保留为被替代版本。初版单卡窗口的计数换行，标题和计数缩短后分别检查三语言实际行数与空间。
