# 施放与费用操作统一（2026-10-14）

## 行为

COST 按用户确认指非单纯法术力费用，例如否认之力放逐蓝牌、村民仪式牺牲生物，以及召集／御水的横置选择。目标选择使用“下一步／取消”；纯普通法术力支付使用“自动支付／取消”。实际选用的费用包含非法术力部分，或本次实际出现横置支付选择时，剩余法术力支付仍用“下一步”。推进按钮在左，取消在右；有重新选择时置于中间。三按钮手牌费用共用底部控件。

费用类别从真实 Forge 费用／费用栈及本次横置输入获取，不按中文提示、卡名、地牌数量推测。替代费用无法支付时，如否认之力缺另一张蓝色手牌，原生普通施放使用“自动支付”；必需的牺牲费用仍由引擎判断，不能绕过。可取消的未完成步骤支持右键，已施放入栈以后不撤销；颜色等序号型 cancel 不是取消。

单张非单纯法术力费用在实际费用栈中标记；公共区域与手牌共享本地草稿。点选／再点取消选择均不发送费用选项，按下一步才提交原候选，完成后的原生 OK 仍由既有单张流程消费。与非费用的单张结算选择区别由实际费用栈决定。原生允许零张确认时保留该合法下一步，不自行假设费用数量。

召集／拼造／御水的输入复用原生选择器，并在允许取消的施放／激活付款中提供取消。取消使整个未完成支付返回失败，由原生施放流程退款；不会当成零个横置对象继续施放。强制／效果付款不新造取消权限；嵌套付款按实际能力身份隔离。

## 验证与边界

- 13 个原生场景通过：闪电击、Divination、村民仪式支付／取消、召集／御水支付／取消及无可用对象的普通回退、否认之力无蓝牌替代费用时的普通付费反击，以及 Travel Preparations／Hex 多目标结果。运行和取消源于真实支付／施放。村民仪式取消核对同物理咒语回手、生物留场、沼泽未横置与池为空。
- 89 条去重 Unity 检查通过，保留原 prefix 与补尾身份；确认按钮语义／位置、右键／重复提交保护、非费用序号、手牌／公共单张费用草稿、三按钮与大量手牌适配、多目标准确原请求及选中数。18 条新旧发送字段形状兼容检查通过。
- 三按钮／大量手牌和费用重试修订号为 UI 适配样本，不计作规则结果。Unity 通过实际请求重放验证展示和回调，没有新增实时跨机验证。无需因桥接调试信息／哈希变化重跑全部旧场景；修改实际横置付款后只补相应支付／取消，费用栈标记后只补村民仪式与对应消费者。
- 多目标截图用原版 Hex：已选 2／须选 6，下一步灰显是原生要求。当前渲染为一条活动目标线，加各个已选对象的金色高亮，不声称每个已选目标各有独立线。满六后真实支付六点法术力并消灭六个目标；Travel Preparations 实际两目标均获指示物。
- 本批不宣称穷举所有 Forge 费用来源；没有新覆盖原生零费用直接完成或所有不可取消的强制／效果付款。目标和额外费用是否合法、何时提交仍由 Forge 决定。
