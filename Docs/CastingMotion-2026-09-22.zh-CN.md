# 施放、取消与目标箭头动效（2026-09-22）

## 录屏参考

参考用户提供的 MTGA 录屏 `MTG Arena_09-22-2026_3-53-44-666.mp4`，逐帧观察 3:52.3–3:54.3，并查看到 4:15。

观察到：手牌抬起后沿短弧线移向右侧，减速停靠；目标箭头随后出现并跟随目标。该片段中看到的是正常支付和结算，没有确认取消回手的参考动作。取消动效按相同运动语言实现，并等待 Forge 确认取消。

## 实现

- `ForgeUiMotion` 使用真实卡面在 Canvas 中的位置、尺寸和角度作为起点，以非游戏时间驱动缓动。图像始终保持宽高比，不使用 X/Y 倾斜或横向拉伸。
- 开始施放时保留规则状态与手牌槽位，仅隐藏重复的手牌图像；同一张预览从原处移动到右侧。
- 目标选择、费用支付、提交等待共用预览，逐条状态更新不会把卡牌隐藏再重建。
- Forge 确认取消、卡牌回手后，预览追踪当前手牌位置返回；确认进入堆叠时，预览衔接到真实堆叠项。
- 堆叠按 Forge 条目 ID 复用显示对象。新增响应时原条目平滑换位，重复快照保留滚动位置。
- 目标箭头增加短暂展开/收起、端点平滑跟随、目标环渐显；始终不拦截鼠标事件。
- 所有规则动作仍由现有 Forge 请求与提交通道决定；动效不修改费用、区域、生命或目标合法性。

## 验证

1. `CastingMotionValidation.Run()`：Play Mode 展示快照检查通过，包括真实起点、非游戏时间、取消回手、快速进堆叠、重复状态不重播、保留堆叠对象和滚动位置、非法/过期目标拒绝、瞬态对象清理，只有三次显式操作回调。
2. `ForgeBattlefieldValidation.Run()`：真实 Forge 与官方 Starter 牌组；下地后施放闪电击，使用场景取消按钮，确认牌回手、生命不变、堆叠为空；再次施放，经目标选择、费用和优先权流程结算，对手 20 → 17。重复点击仍只提交一次。
3. `AttackDefenderPresentationValidation.Run()`：真实 Forge 快照回放，攻击玩家/旅法师/战役的拖曳、点击、撤回、非法与过期操作检查通过。
4. `ArenaPresentationValidation.RunStack()`：三张堆叠可滚动到底、重复快照保留滚动、详情点击可用、目标预览与堆叠不重叠；落点整行延迟显示，避免空白底框闪现。
5. 结束前 Unity Console 无 error。本轮验证为 Editor Play Mode，未重新打包 Windows。
