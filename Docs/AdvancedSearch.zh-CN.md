# 卡牌高级搜索

卡组编辑器的“高级”按钮打开独立草稿。条件之间为 AND；点击“查看结果”才应用，取消保留原结果，重置清空草稿。工具栏普通搜索与已应用的高级条件组合，翻页不重复执行整库筛选。

支持卡名、规则文字、类别/副类别、颜色与颜色标识、费用符号、法术力值、力量/防御力/忠诚度、稀有度、系列、画师、发行日期、版式、来源与赛制合法性。可排序或每张卡只保留一个版本。

- 名称、类别和规则文字匹配英文原文及当前界面的译文，包含双面牌及其他部分。空格分开的文字条件须全部匹配。
- 数值支持 `= != < <= > >=`，如 `<=3`。变动力量、牌面忠诚度为 `X`、`*` 或空白的情况均不参与对应的数值比较。印着 `0` 的忠诚度可以搜到。力量、防御力、忠诚度和费用符号须在同一牌面满足。
- 费用输入 `{U}{U}` 表示含至少两个蓝色符号；混合/非瑞克西亚符号以完整符号匹配，如 `{B/P}`。
- 费用和类别输入框右侧的“插入”菜单会插入到光标位置，或替换选中文字，完成后光标留在插入内容后。费用按数据编辑器的符号分组，支持 `{Z}` 和无色混血等符号；类别按类别、超类别及副类别分组，副类别来自当前本地卡库，可搜索选项。类别插入规范英文类型词，并自动补足词间空格。
- W/U/B/R/G 是白蓝黑红绿，C 是无色；颜色匹配支持任意、全部、恰好、仅所选颜色。“仅所选”包含无色。
- 系列一览选取印次代码。手动输入支持代码、完整的中英日系列名和名称片段；多个系列以逗号或分号分隔，取并集。
- 指定赛制时使用 `DeckFormatLegality` 的本地现行规则，逐印次判断。“合法”包含限一，“限一”和“禁止”可分别单查。赛制选“不限”时，官方印次在任一有记录的赛制符合所选状态即可。
- 仅调整排序、合并重印或切换卡牌来源时，保留相应来源的卡池。启用印次筛选时，平台沿用窗口勾选项，初始为纸质。
- 版式沿用资料源的 layout，普通版式是 `normal`，传纪/职业另列。

## 本地资料

`Assets/StreamingAssets/CardSearch.jsonl` 是独立的派生搜索资料，不改动规则卡库。由现有本地 Scryfall bulk cache 和 Forge 卡牌目录精确匹配印刷编号及名称生成：

```powershell
python Tools/ForgeBridge/Export-SearchMetadata.py
```

输入为 `.tools/card-images/default-cards.jsonl.gz` 和 `ForgeRuntime/catalog.jsonl`，脚本在本地生成索引。当前卡库有 97,784 个印次，其中 97,080 个有精确匹配的搜索资料。其余印次仍可从卡库浏览或通过外层文字搜索找到。官方印次在高级筛选中按所勾平台匹配，缺少平台资料时会被排除。DIY 卡使用独立来源。

资料仅在首次打开高级搜索时后台读取，不增加启动阶段的解析。文字和费用判断在一次查询内按卡名/费用缓存，印刷版专属条件仍逐版本判断。

## 验证

在主界面进入 Play 模式并等卡库和语言资源就绪后，Unity 菜单 `MTGB/验证/卡牌/高级搜索` 运行组合条件、当前语言与背面名称、颜色标识、同面数值、印次合法性、非法输入、排序去重和整库扫描验证。结果位于 `SessionState["AdvancedSearch.Validation"]`。

### 2026-11-18 高级搜索回归

- Unity Play 模式，中文界面，61 项通过。覆盖平台的八种勾选组合、白蓝颜色及颜色标识的四种匹配模式、系列代码和名称、多条件交集、日期端点、数值和费用符号、过滤后的排序与合并。
- 在右侧卡库单独按法术力值排序，保留全部 97,784 个印次，逐项顺序与法术力值、印次键排序一致。输入超长数值后，“查看结果”提示格式错误，取消保留原结果，外层重置恢复全部卡库和默认按钮颜色。
- 法禁指挥官原先有 28 个同名印次与本地规则不一致。修复后按本地 2026-07-27 禁限表逐一比对 97,080 个有资料的官方印次，差异为零。特选的限一牌可以在“合法”和“限一”中找到。
- 在右侧卡库应用 `ONE；ELD`，结果为 ONE 479 个、ELD 397 个，与逐印次比对一致。窗口内重置后，在点击“查看结果”之前仍保留原来的 876 个结果，应用后恢复 97,784 个。全库以卡名、法术力值或发行日排序并合并重印，三种方式均得到 33,980 个不同卡名，顺序与最终印次一致。
- 按印次代码、编号和牌面名核对 [Scryfall 印次数据](https://scryfall.com/docs/api/cards)：现有搜索资料中，Forge 忠诚度为零、空白或非数值的 29 个鹏洛客印次共需校正 21 条。默认纸质平台查询 `=0` 返回 Jeska, Thrice Reborn 和 Dakkon, Shadow Slayer 各 3 个印次。其余 8 个印次原本就是数值零。
- 完整 bulk 压缩缓存本次未在本地找到，现有索引以 29 个精确印次的数据增量更新。校验过全部 97,080 条索引的印次键和原有字段。这次核对的范围是编辑器搜索结果，未验证对局结算或独立构建。

## 2026-10-23 OM1 异画与合并显示

OM1（穿越预兆路）与 SPM 原版在本地已共享 Forge 牌名及 oracleID，CardArtVersions 会把两者放在同一异画列表。原“每张卡只显示一个版本”直接保留结果中首项，究极蜘蛛侠实际默认得到 OM1/140；该行为不能由“默认平台是纸质”推定，因为普通列表未应用高级条件、或平台包含MO时，仍有合并代表选择的问题。

本次只改 AdvancedCardSearch.Order 的 Unique 分支：当前查询结果同时包含同名 SPM 和 OM1 时，以结果内的 SPM 替换 OM1 代表，再按原有同名去重。没有从查询之外补牌；明确只筛OM1时仍保留OM1。全部版本模式仍展示全部，平台筛选默认纸质及其元数据保持，异画菜单仍可选OM1。不改卡牌身份、牌组、原生费用或规则。

证据 `.tools/om1-art-1023/`：Unity 实际加载本地卡库，189个OM1印次均有SPM对应。四种排序的合并代表、仅OM1、全部版本及异画分组共1323项通过；Play模式语言资源Ready后，实际筛选查询3项通过：默认纸质/全平台选择SPM/155，仅OM1+MO选择OM1/140。查询条件中没有偷偷切换平台。小范围算法与真实数据检查，不授予整个高级搜索或原生效果通过。

旧 AdvancedSearchValidation 整套校验另有驱动限制：首次Edit模式GamePreferences.Ready=false导致平台检查失败；进入Play并等Ready后，旧“Japanese search”仍假设非当前语言也可搜索，而当前实现只查已加载语言，失败原件保留为 `edit-mode-not-ready-advanced-results.txt` 和 `legacy-validation-current-locale-failure.txt`。本批不修改该历史驱动、不声称整套通过；新专项与查询证明独立。仅客户端源码修复，尚未打包覆盖或发布Git。
