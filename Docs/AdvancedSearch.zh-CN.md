# 卡牌高级搜索

卡组编辑器的“高级”按钮打开独立草稿。条件之间为 AND；点击“查看结果”才应用，取消保留原结果，重置清空草稿。工具栏普通搜索与已应用的高级条件组合，翻页不重复执行整库筛选。

支持卡名、规则文字、类别/副类别、颜色与颜色标识、费用符号、法术力值、力量/防御力/忠诚度、稀有度、系列、画师、发行日期、版式、来源与赛制合法性。可排序或每张卡只保留一个版本。

- 名称、类别和规则文字匹配原文及中日文译文，包含双面牌及其他部分；空格分开的文字条件须全部匹配。
- 数值支持 `= != < <= > >=`，如 `<=3`。变动力量 `*` 不当作数值零；力量与防御力条件须落在同一部分。
- 费用输入 `{U}{U}` 表示含至少两个蓝色符号；混合/非瑞克西亚符号以完整符号匹配，如 `{B/P}`。
- 费用和类别输入框右侧的“插入”菜单会插入到光标位置，或替换选中文字，完成后光标留在插入内容后。费用按数据编辑器的符号分组，支持 `{Z}` 和无色混血等符号；类别按类别、超类别及副类别分组，副类别来自当前本地卡库，可搜索选项。类别插入规范英文类型词，并自动补足词间空格。
- W/U/B/R/G 是白蓝黑红绿，C 是无色；颜色匹配支持任意、全部、恰好、仅所选颜色。“仅所选”包含无色。
- 系列接受代码或英文名称；多个系列用逗号分隔，系列之间为 OR。
- 赛制使用 `DeckFormatLegality` 的本地现行规则，并不在线获取禁表；“合法”包含限一。选择“不限”时状态条件不生效。
- 版式沿用资料源的 layout，普通版式是 `normal`，传纪/职业另列。

## 本地资料

`Assets/StreamingAssets/CardSearch.jsonl` 是独立的派生搜索资料，不改动规则卡库。由现有本地 Scryfall bulk cache 和 Forge 卡牌目录精确匹配印刷编号及名称生成：

```powershell
python Tools/ForgeBridge/Export-SearchMetadata.py
```

该脚本不访问网络。输入为 `.tools/card-images/default-cards.jsonl.gz` 和 `ForgeRuntime/catalog.jsonl`。更新这两份源资料后应重新生成。当前匹配 96,637 / 97,120 个版本；缺失资料的版本仍能做文字搜索，但不参与依赖该资料的颜色、颜色标识、法术力值、稀有度、画师、日期和版式条件。DIY 卡不套用官方同编号的资料。

资料仅在首次打开高级搜索时后台读取，不增加启动阶段的解析。文字和费用判断在一次查询内按卡名/费用缓存，印刷版专属条件仍逐版本判断。

## 验证

Unity 菜单 `MTGB/验证/卡牌/高级搜索` 运行组合条件、译名、背面名称、虚色/颜色标识、同面数值、非法输入、重印去重和整库扫描验证。结果位于 `SessionState["AdvancedSearch.Validation"]`。
