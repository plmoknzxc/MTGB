# 随机结算的费用、限次与持续期边界

固定 Forge：`4ec5f1a2c32fa90ecb983a72b9eb47aa5c5d7676`。本轮不修改卡牌规则、翻译、卡图或 Forge 二进制；代表牌沿现有共用付款、二选一、重掷多选、战场更新界面。

## 七个真实规则场景

`RandomBoundaryFixture.java` 只放置初始牌、地、计数与身材；继承的只读观察器保存原生骰值、物理掷骰次数和完整私人牌库编号，另一个只读观察器保存原生 `ModsThisTurn`。它们不设置随机结果、不强制改限次、不直接执行目标效果。

| 场景 | 实际操作及断言 |
|---|---|
| Monitor 费用不足 | 仅四张海岛；真实施放支付四点后无剩余产费。选骰并确认后，原生付款只提供取消。取消后再次明确选择保留，原骰值完成结算；无额外付款、无额外掷骰、没有消耗限次 |
| Monitor 取消再试 | 有可用法术力仍取消第一次付款；原生返回重掷选择，再次选骰确认、真实支付一点后重掷。额外物理骰仅一次，限次只记成功付款 |
| Monitor 每回合一次 | 真实施放三个 Contact Other Plane：第一次付费重掷，同回合第二次没有重掷请求；原生新回合将限次归零，下个自己回合第三次可以再次付款重掷 |
| Night Shift 每回合一次 | 第一次真实付一点生命并增加骰值，同回合第二次没有修改请求；新回合原生限次归零，第三次再次付生命修改。最终生命 18，各次骰值、库顶顺序和抽牌分别核对 |
| Night Shift 禁止付生命 | 初始白金帝像使生命不能变化；实际施放没有骰值修改请求，不付生命、不用限次，按自然骰值完整结算 |
| Xenosquirrels 最后指示物 | 初始一个 +1/+1 指示物，原生移除后修改骰值；状态动作令 0/0 生物进坟墓场且指示物清空，咒语仍继续按修改后结果结算 |
| 身材交换持续期与换区 | 初始 Whacker 4/5；Fly 真实支付四点、掷骰交换力量成为 4/4。回合结束 Fly 失去生物类别、身材与飞行，Whacker 交换的身材继续存在。真实 Unsummon 支付一点回手，再支付四点重施；同一牌编号重新执行两个进战场骰，身材对应这两个新结果 |

每次咒语另核对真实费用、原生物理骰次数、保留结果数量、占卜数量、抽到的准确库顶编号和剩余完整牌库顺序，最后恢复原生优先权。跨回合场景实际通过阶段、清除阶段弃牌和下一回合重置，不直接拨动回合数或限次。

初始放置 Monitor 不证明它进战场打开 Attraction；初始 Whacker 的 4/5 不冒充它初次进战场效果，但回手重施后的两个进战场骰有实际证据。费用不足代表无可产费，并未穷尽每一种费用替代或产费限制。

## 共用界面修复与检查

费用取消原本一律写“取消施放”，提示又写“尚未完成施放”。重掷付款在咒语结算中发生，取消该付款后原咒语继续，文案错误。现在统一显示三语言的“取消支付”，付款提示显示原生当前费用；优先读协议的 `remainingManaCost`，没有该字段时读取固定原生付款正文的费用行，不在客户端重算费用。

`RandomBoundaryPresentationValidation` 重放真实费用取消请求和随后返回的重掷请求：实际按钮中心射线、原生选项编号、可操作时旧编号拦截、重复提交、非操作玩家拦截，以及下一请求恢复启用和明确保留确认。三语言检查文案、固定字号和实际测量的提示高度。另重放 Fly 动画／到期／换区／重施后的原生快照，核对飞行和身材控件、Whacker 当前身材、死亡生物移除，以及结算后没有残留选择菜单。总计 36 张中／英／日稳定状态截图。

这些是生产界面的请求重放，实际费用与效果由前述规则场景证明；不称为真实联网对局或完整施放预览、动画过渡测试。无对局回放临时隐藏无对局提示条，结束时恢复；其他控件与实际射线继续启用。

## 失败和采样复核

早期测试驱动未读取原生费用正文、误把咒语付款的 `{1}` 当重掷付款、没有为第二次咒语保留蓝色来源、第二次施放的生命断言错误，以及多张清除阶段弃牌过早确认，分别保存在 `.tools/random-boundaries/attempts/`，未归为 Forge 规则缺陷。

第一轮界面检查误按 `Keyword_Flying` 查找原生大写 `Keyword_FLYING`，源快照和实际控件均正确；修正测试后复测。第二轮通过了按钮检查，但截图暴露上方仍称“尚未完成施放”；第三轮新文案过长，在付款提示中被截断。第四轮的实际高度断言进一步发现英文在用户现有 1.3 倍字号下换成三行。继续缩短文字，保留用户字号设置；第五轮三语言、固定字号与实际文字高度检查均通过，36 张截图全部解码为 1560×898。该尺寸／倍率／代表费用的通过不证明全部长费用和所有字号、设备均通过。各轮结果与截图保存在 `.tools/random-boundaries-ui-attempts/`。两个全量引擎批次 `20261003T183420465021Z` 与 `20261003T183748177683Z` 因修正生产提示／界面断言主动停止，保存 `interrupted.txt`；部分通过不算完整回归。

## 保留缺口

多骰、多个重掷／修改来源、固定数值修正、指定值、吸引力骰、平面骰、其他费用类型、更多生命支付限制、额外玩家／控制玩家、替代或触发组合及真实网络时序仍须单独验证。公共结果通知发生在原生固定数值修正之前，不能一概称为最终结算值。既有英文异能盾、其他通知接口和全部长文本仍有缺口。共用界面通过不会自动给其他卡牌的规则或所有分辨率标记 PASS。

本轮新展示可以沿现有交互复用，没有新增必须由用户决定表现形式的机制；总目标仍继续，后续按照结构清单和流程缺口补验。
