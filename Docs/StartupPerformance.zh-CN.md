# 启动加载优化（2026-09-22）

## 2026-09-25 预生成卡牌数据库（当前普通启动路径）

- 编辑器进入 Play Mode 前以及 Player 构建前，自动检查并生成 `ForgeRuntime/catalog.mtgbcache`。也可用 `MTGB/数据/重新生成卡牌数据库` 强制重新生成。源目录/风味文字变化会触发重建；版本检查失败会停止构建或进入运行。
- 生成阶段沿用原 Forge JSON 投影和风味文字关联，预先完成字段转换。二进制数据库采用共享字符串表，复用各印刷版本相同的牌名和规则文字；不存卡图或执行脚本。
- 普通同步/异步读取直接加载预生成数据库到内存。只检查小型运行配置、格式版本、来源版本标识和记录边界，不再读取、哈希或解析原始 `catalog.jsonl`/`CardFlavor.jsonl`。源文件完整性检查移到编辑器/构建阶段；显式完整重载仍保留原完整校验路径。
- 主菜单等卡牌数据和当前界面语言就绪后显示。菜单出现即可进入卡组编辑，卡图仍按需加载。数据缺失或版本不符会明确报错，不静默退回慢速 JSON 加载。
- `ForgeBuildMenu.CopyRuntimeTo` 会复制这份数据库；它是可重建的发布产物，位于已忽略的 ForgeRuntime 中，不是用户编辑的卡牌源数据。

验证：`MTGB/验证/卡牌/预生成数据库` 对比全部 97,120 个印刷版本的序列化字段、所有牌面、规则文字、风味文字、来源路径和警告，并验证缺失、截断、版本错误、来源不匹配和取消。

本机编辑器、同一测试中的原 JSON + 风味文字读取 14,559 ms；预生成数据库三次独立读取为 2,114 / 1,643 / 1,121 ms，文件大小 23,761,534 字节。未清空操作系统文件缓存，不能视为磁盘冷启动指标。

最终实际 Play Mode：Data ready 1,194 ms；本轮菜单及语言就绪为 3,096 ms（从控制器计时起，不包含编辑器完整进入 Play Mode 的时间）。首个可见菜单自动点击卡组编辑，已验证立即进入、无排队等待，日文界面和卡名正确。Windows 独立 Player 的启动耗时尚未实测。

补充完整验证轮：原 JSON + 风味文字 2,804 ms；预生成读取 347 / 181 / 402 ms。编辑器负载会影响绝对耗时，应对比同一轮而非跨轮挑选数字。本轮还验证了仅有 `runtime.json` 和预生成数据库、没有原始 JSON/风味文件的独立目录仍可完整加载全部卡牌。

## 2026-09-24 联机流程调整

普通启动和同步读取卡牌目录均跳过完整 Forge 资源扫描，仍检查目录文件自身的哈希。入房握手只发送客户端协议版本与发布版本标识，不再访问 Forge 文件或比较双方资源哈希。权威端开局只检查本地桥接配置和必要路径。完整逐文件校验保留在显式重载和下述完整加载验证中；以下早期计时记录的是完整校验模式，不再代表正常进入菜单或联机的耗时。

## 范围

优化 Forge 卡牌数据准备，编辑器与 Windows Player 共用运行时代码。没有改变规则、卡牌内容或资源校验标准。

## 改动

- 55,581 个运行资源由逐个串行 SHA-256 改为最多 4 路并行，低核心数设备按 CPU 数量限制并发，每个工作线程复用哈希对象。
- 完整运行资源校验与卡牌目录解析同时执行；两项都成功并检查取消标记后才返回卡牌。两项任务都会等待结束，防止失败或取消后遗留后台加载。
- 仍检查每个文件内容、清单哈希、目录哈希、路径越界/重复、额外文件以及 Java/资源目录配置。
- 进程内校验缓存增加运行目录键，防止两个不同安装目录错误共享校验结果。
- 显式「重载」会清除运行资源校验缓存，重新验证资源。
- 没有新增跨启动信任缓存，不依靠文件大小或修改时间跳过完整性校验。

## 测量方法

同一台电脑、同一份固定 Forge 数据、Unity 6000.3.22f1 Play Mode。强制清空运行资源校验结果后测完整加载，包含风味文字关联。文件系统缓存未清空，因此不是操作系统冷启动测试。

优化前分阶段实测：校验 13,139 ms；目录解析 3,143 ms；风味文字 397 ms；合计 16,679 ms。

仅改并行校验的中间版本：校验 5,313 ms；解析 2,883 ms；风味文字 342 ms；合计 8,538 ms。

最终版本菜单实际 Data ready 日志：9,643 ms、9,721 ms。此计时从数据加载开始，**不包含**编辑器进入 Play Mode 和菜单首帧耗时，不代表点击运行至完全可用的总时间。

## 复验入口

Play Mode 中等待菜单数据就绪，执行 `MTGB/验证/启动加载`。

脚本：Assets/Scripts/Editor/StartupLoadValidation.cs。
执行三次强制完整加载，验证 97,120 个版本；在隔离的 .tools/startup-validation 目录验证损坏、缺失、未登记资源、目录/清单篡改、取消及失败后重试。原 ForgeRuntime 不会被测试修改。

本轮未重新构建 Windows 可执行程序，打包启动耗时尚未实测。运行时代码不使用 UnityEditor API。
