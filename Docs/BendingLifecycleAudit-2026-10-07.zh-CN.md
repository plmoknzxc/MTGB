范围为原 R27：土地变生物、换区后施放许可、实际支付／返回及对象身份。复用现有特征详情、跨区施放、普通目标和付款控件；本批只补状态、许可和跨区域目标列表的差异。结果文件为 `.tools/bending-lifecycle-1007/result.json`，各成功场景保留自己的驱动副本及哈希。

只读资源复核包含 21 个操作末态、四次准确两点替代支付的原生审计、拥有者第二回合时序、池与生命以及取消前后的完整资源恢复；仅排除两个已知派生分组提示。没有直接修改结算结果。

第九条原生流程已经写出最终快照并通过原驱动的 outcome 断言，但汇总函数被同名局部字符串覆盖，写报告失败。保留原 run-summary 的 FAIL 和缺失 result.json 的原目录。`repair-reporting.py` 独立核对原轨迹、双方最终公开战场、指定 ID、原生付款与零目标结束候选，输出明确标识的 `decline-recovered.json`；没有重跑或伪造原报告。当前驱动只将局部变量改名为 finish_choice。

其他失败分别为驱动漏识别对话框、错误施放时机、测试来源法术力不足、读取省略的 token:false 字段，以及误选区域标题造成无进展。成功场景不因后续修驱动统一重跑。

## 界面差异与修复

运行中确认原生 `--CARDS ON BATTLEFIELD:--` 被渲染为 `SelectionAction_0` 按钮。Forge 的 TargetSelection 把六种区域标题混在选项数组中，点击标题不选择卡也不结束目标，导致再次询问。修复只在含真实卡候选的 dialog 中过滤准确六种标题，保留卡牌及结束选项原索引；有该标题合同的 `[FINISH TARGETING]` 显示三语言“确认目标”。普通付款、目标请求、任意字符串选择与 Forge 运行包不改。

UI 证据以最终 steps.log 和原始尝试分别记录：运土前后及返回后的双方准确 ID／行位置／攻防／指示物／详情；第二次死亡清理；截气施放区、取消后重试、付款的实际数字 2 Sprite 与真实取消／自动支付射线；许可失效及来源离场；拥有者真实点击与另一席位没有施放区、提交被拦截；三语言跨区卡候选及可选结束按钮原索引；相邻永恒拉回普通目标窗口回归。既有三语言特征、普通目标、支付与私有信息合同引用旧证明，本批为 UI 增量，不增加 UI 首验。

测试修正也保持界限：提交后控件会主动禁用射线，这是正确防重复行为；另一席位的 playableExile 为空，不能要求存在可点击施放卡；TMP 数字符号采用 PUA 字符，核对实际 TMP_SpriteCharacter.name，而不是要求文本含 sprite 标记。已完成的 9、14 项成功结果保留，仅继续剩余检查。
