# 原生费用与基础界面边界复核

## 本轮发现与修复

真实施放 Jötun Grunt，经过原生回合进入累积维持，选定坟墓场并选中一张牌后取消，实际触发 `NullPointerException`：`chooseCardsForCost` 返回取消结果，`PlaySpellAbility.payCostDuringAbilityResolve` 仍将它交给 `GameActionUtil.orderCardsByTheirOwners`，后者访问空列表。取消不是正常游戏终止，不能将这个失败算成玩家输局。

`NativePatches.json` 在排序前检查取消或不足额结果并返回未支付；继续由原生累积维持结算牺牲来源。没有改写费用、年龄数量、合法选项、牌库顺序或玩家选择。修正仅针对固定提交 `4ec5f1a2c32fa90ecb983a72b9eb47aa5c5d7676`；构建先核对完整源文件哈希与唯一替换上下文，再生成、编译修正类。上游目录保持原始内容，完整生成源码和变更清单随运行包保存，其他人重建不能漏编修正类。

生产 `OnlineMatchSession` 的 Java 类路径将 `ForgeRuntime/classes` 放在 `lib/*` 前，使用生成的修正类覆盖固定 jar 内原类；独立核对生成 class 与运行包 class 的字节完全一致。包内原生补丁清单、生成源码和重建说明也与工作区一致。

桥接给这类独立放回牌库费用附当前来源和用途，客户端区分选坟墓场的玩家与选支付牌，显示本地化的支付／取消含义。混合其他费用类型不套用此用途标签。中、英、日的费用及排序标题采用简短文字，选牌数量仍取原生请求。

界面检查还发现，新动态提示等周期偏好扫描后才从原字号变为用户的 1.3 倍字号。费用／排序的标题、数量及说明现在在创建时立即应用偏好；说明关闭自动缩放，断言实际高度和连续选牌时字号稳定。并未声称项目所有动态文字的首帧都完成验证。

## 真实规则场景

`LibraryCostFixture` 只预置牌、土地、初始坟墓场，并只读记录牌库完整编号；不设置年龄、付款、阶段、牺牲或排序结果。驱动用生产请求真实施放、支付两点法术力、让过优先权、进入实际维持并作选择。

| 场景 | 明确断言 |
|---|---|
| own | 自己坟墓场两张牌，准确编号、拥有者所选牌库底顺序、其他牌库完整不变；来源存活为 4/4、年龄一、继续优先权 |
| opponent | 来源控制者选对方坟墓场的牌；牌拥有者在另一个席位排序，原生操作席位正确；准确区域及完整顺序 |
| seat-two | 第二席位真实施放和支付，自己的维持选择与取消入口正确，没有固定第一席位假设 |
| cancel-player | 取消选玩家，无费用牌移动；来源牺牲，两方完整牌库不变，继续优先权 |
| cancel-card | 选中一张后取消，不排序、不移动支付牌、不崩溃；来源牺牲，完整牌库不变，继续优先权 |
| insufficient | 实际维持时两方墓地各不足两张，没有付款选择；年龄产生后牺牲来源；区域、完整牌库及优先权 |
| second-age | 两次实际维持，年龄一到二；第二次原生重复两次两张牌费用；共六个准确编号和每次拥有者排序，不用四张合并选择代替原生请求 |

测试把自然抓牌、手牌上限和清理阶段弃牌计入前置状态，不把对方正常弃入墓地的牌误判为费用污染。每次费用前后检查完整牌库，正常支付还核对底部完整顺序，取消检查全库不变。对手手牌不进入另一席位快照。

## 基础边界与继承检查

- 两层接口有 **105 个 IGuiGame 声明、48 个 IGuiBase 声明**。基础层增加完整签名（含 throws）、默认方法体／来源守卫、玩家／输入／gui-util 内 **25 个直接基础或辅助调用位置**。接口中未接入功能明确抛异常，保留的关闭能力和由 Unity 负责的展示项按名称列出；新 boolean／void 回调不能再默认 false／空返回。
- 运行反射表解析 **145 个 PlayerController 非私有实例方法声明**：31 个在基础控制器、100 个在 Human、14 个在桥接实现。重载按准确参数类型解析，未将所有同名方法合并。
- `base-defaults`、`base-unsupported` 是两项适配器／结构检查，**不是卡牌效果场景**。检查原生默认转发、环境能力与未支持选择／任务不能被悄悄忽略；反射表不证明所有实现分支的行为。
- 本轮图工具返回 `Transport closed`，没有当前代际／图覆盖证明；通过准确源文件、直接调用扫描、固定哈希和运行反射补证。

最初源码查看发现 `HumanCostDecision.putFromSame` 调用全局 `SGuiChoose`，但实际 Jötun 累积维持走 `PlaySpellAbility` 的单独支付分支，发出正常实体和卡牌输入。潜在全局辅助缺口与本轮实测崩溃分开记录；没有把未运行的路径写成已发生的错误，也没有靠推测操作玩家接入全局选择。

## Unity 范围

`LibraryCostPresentationValidation` 重放以上真实请求，中／英／日分别检查：合法玩家头像射线、选中后确认、取消支付、原生来源和数量、确认门槛、卡图选择、卡牌及面板身份稳定、准确选项编号；可操作时的旧请求、重复提交和不可操作玩家独立拦截。对方拥有的支付牌在对方视图排序确认；正常存活、年龄二以及牺牲后的快照检查没有残留选择框或战场对象。

这是实际请求重放的 UI 检查，规则效果由 Python／Java 场景独立证明；不等于运行完整网络对局、动画时间或全部设备。当前完整批次证据以自动清单为准，完成后在本文件追加。

本轮三语言断言只覆盖所列支付／排序提示、数量和取消／确认语义。截图中的原生堆叠异能正文仍可能为英文，其他战场标签及日文界面的重置选牌按钮仍有中文；这些语言缺口保留，不能据三语言截图宣称整页翻译完整。

## 失败与剩余范围

原生取消崩溃、早期驱动的清理弃牌与计数假设错误、首帧字号变化、测试自身复用已销毁的页脚按钮、过长英文提示的高度失败均保存在 `.tools/library-costs/attempts/`、`.tools/library-costs-ui-attempts/`。修复后需重新采样；失败截图不标成最终通过。

D 盘满时构建曾中断。旧 30 轮轨迹共 11,278 个文件做 ZIP 后逐文件 SHA-256 复核；删除副本的自动审批被拒绝，因此保留全部原始文件搬到本任务 C 盘输出目录，用原路径的目录链接保持证据可读。最近一轮仍在 D 盘原位；压缩包和证明另保留。ZIP 哈希 `69a65bf310fb50d4b5aa55bebaa12bda38490f9d1480b7e10808b6082fe3a293`，没有丢弃或改写旧失败。

仍需验证：多来源／多类型费用的部分取消、替代费用与替代区域转移、嵌套玩家控制／多人、其他游戏模式、全局辅助的别名及间接调用、更多数字机制及跨局结构。两层接口分类、继承解析和七个新场景不能当作全卡池证明。共用表示减少需要单独搭建的界面，但每种原生结算和关键边界仍要有断言。
