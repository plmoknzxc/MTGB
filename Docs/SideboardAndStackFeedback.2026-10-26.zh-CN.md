# 备牌入口与顶部堆叠反馈

复制战场的备牌入口按当前原生优先权选项发亮：自己的已知备牌中，至少一张有未禁用、无需继续核验费用的 card:id，且当前可行动、尚未提交。复用 RedesignPayableSourceIds，不根据愿望术牌名、长期许可或备牌数量猜测。入口文字变亮青色并加轻青底；悬停结束恢复可用底色，而不是清空。消耗、到期、费用不足、非行动／录像视角恢复普通外观。其他区域入口不新增高亮。

新版堆叠此前关闭了已有 ForgeStackGlow。现将同一流动闪光网格拟合整条紧凑行，而不是只闪缩略图；保留敌我底色和边线。沿用旧版条件：索引 0 顶部待结算对象闪烁，选目标时关闭，重排／移除后跟随新的顶部物理堆叠 ID，清空后移除。没有新增“引擎正在执行某一步”的协议字段；不是所有待响应对象一起闪。普通配置仍把组件放回原卡面，未改变旧场景资产。

验证 validate-sideboard-stack-feedback.cs，sideboard-stack-feedback.json：中／英／日三窗口、标准／大字，共105项通过。使用上一轮真实愿望术请求核对许可前／响应／消耗／到期／无蓝费／备牌地、费用待核验适配器、非行动视角、悬停恢复、真实入口射线与浏览无提交；堆叠两帧网格颜色确实变化、只有顶部激活、完整行尺寸、换序跟随ID、异能、选目标抑制／恢复、清空及不拦输入。首轮27个成功前缀后，测试反射遇到基类 OnPopulateMesh 重载歧义；保留 sideboard-stack-feedback-round1-reflection.json，指定 VertexHelper 重载后完成，无生产逻辑迁就。
