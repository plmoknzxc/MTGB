# 地产费异能选择窗口（2026-10-16）

用户确认问题为“选择异能或施放方式”的大卡牌窗口，而非选色小框。仅修复客户端展示与桥接标记，保留前批未发布的牌库、选牌排版等修改；不打包、不安装运行包、不部署，旧 goal 仍暂停。

## 原因与处理

真实 Tropical Island 请求的选项是 `{T}: Add {U}.`／`{T}: Add {G}.`。旧 `ChoiceManaSymbols` 只认纯颜色或 `Add {U}.`，不认横置费用前缀，所以把这一步画成两张大异能牌。Llanowar Wastes 的另一选项还包含对自己造成 1 点伤害，旧代码为避免隐去副作用也进入大卡牌模式。Lotus Field、City of Brass 的后续颜色选择原本已是紧凑图标。

- 对准确的原生激活合同识别单独 `{T}:` 加纯产费正文，使用来源附近的颜色图标，并以“横置产费”明确共有费用；不剥掉其他费用或附加效果。旧服务端的这一纯产费形式也能使用图标。
- 桥接只在候选真实异能全部 `isManaAbility()` 时标记既有字段 `selectionPurpose=manaAbility`。客户端对有费用／条件／副作用或多符号产出的候选使用紧凑文字行，保留完整翻译和费用／法术力符号，不重复卡图。
- 混有非产费异能的选择继续按原合同显示说明；只改渲染，不替玩家决定颜色、自动激活或更改原生合法选项与规则结果。
- 沿用原索引／请求编号提交、禁用、重复提交防护、外部／右键取消及查看战场恢复。长行按当前字体测高，确有溢出时滚动到末项。

生产修改只在 `ForgeBattlefieldController.LandChoices.cs` 与 `ForgeBridge.java`；未修改卡牌资料、翻译或规则脚本。高级产费元数据需未来两端一起更新才能在当前服务器上使用。

## 证据与增量范围

本批 `.tools/mana-choices-1016/` 保存初态、真实请求／双方视图、结果、隔离 class、前后 UI 图与检查。原生底包仍是 `4ea47c5d…`；运行时先加载本批桥接，再加载上一批 `.tools/library-browser-1016/classes` 的待发布依赖，最后加载根 ForgeRuntime。此类路径叠加不是根运行包已更新。

- 先复现真实请求：Tropical Island 和 Llanowar Wastes 均为 432 高、两张大卡图；Lotus Field／City of Brass 为小图标框，反例记录 `before-native-native.txt`。
- 五个真实激活完成：Tropical Island、Llanowar Wastes、Lotus Field、City of Brass、Nykthos。断言准确源牌横置、产费数量和生命／副作用；其中 Nykthos 实际选择无色分支，**不授献力分支效果 PASS**。第六个 Kessig Wolf Run 只核对真实混合候选没有标记为全产费，不宣称已结算其加力量异能。
- 当前真实请求 UI 255 项：三语、正常／最大字号、图标／完整文字行／混合卡牌类型、实际费用和伤害／献力翻译、完整行高／画布范围、真实射线、准确选项只提交一次、非操作者禁止提交。请求内容来自原生，展示使用同一消息中接收者的 view 加 request，独立于效果验证。
- 8 条符号边界：旧纯横置产费识别，额外法术力／生命费用、非产费／附加效果不误隐藏，限定激活合同，无色与召集通用支付仍各用 C／1。
- 取消、旧请求、禁用、旧服务端图标、真实多行溢出与末行可达单独记录。原“查看战场”断言误以为节点须 inactive；生产明确使用 CanvasGroup 隐藏以保留状态，旧 FAIL 保留，按实际 alpha／交互／射线合同补验证 `restore-boundary.txt`。

首版 UI 驱动只取原生消息的 views，未合并其独立 request，实际未显示选择却被错误记作紧凑失败；保存原结果 `before.txt`，随后使用正确激活 view 的复现为上面的前后依据。未为驱动错误修改生产。

新原生修改仅为 `getAbilityToPlay` 模态请求加标记；移除此新增块后与本批基线 ForgeBridge 逐字相同，原牌库／通知／选择规则消费者据此做影响复用，不重复其已完成结算。当前检查不授全卡池、全部费用／产费组合、完整公网对局或内存峰值结论。

机制覆盖工具只刷新分类（不带 `--run`），历史任务不改授当前通过。最终源码与依赖、class、输入和证据哈希集中在 `audit.json`。
