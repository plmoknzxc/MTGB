# 主牌费用曲线与类型统计（2026-10-16）

## 使用

卡组编辑主牌标题栏在排序按钮前增加「查看曲线」。点击打开统计面板，显示当前编辑中的主牌费用柱状图和类型张数；不要求先保存。关闭按钮、Esc 或点击面板外返回组卡。

- 按 `DeckEntry.count` 统计实际张数，不按不同印刷版本的条目数统计。只读取 `currentDeck.cards`，备牌、主将、行侣和辅助牌组不另行计入。
- 费用曲线统计非地牌，横轴为法术力值，始终从 0 开始，至少显示到 7；中间没有卡牌的整数档位保留 0 张。优先复用搜索资料中的法术力值；DIY／缺少资料时沿用现有费用排序的解析，X 为 0、混合／非瑞克西亚符号按对应法术力值计算。
- 小数法术力值保留独立档位。常规整数档位最多补齐到 20，更高的实际费用仍以独立、精确档位显示；不按巨大 DIY 数值生成等量空控件。档位较多时可横向拖动、滚轮或拖动滚动条浏览。
- 类型列表包含生物、瞬间、法术、神器、结界、鹏洛客、战役、亲缘、地。多类型牌计入每个对应类型，因此类型数字相加可能超过主牌张数。未知类型／未识别印刷在有对应牌时单列，地不并入 0 费柱。
- 排序及曲线入口沿用文字宽度测量，窄主牌栏会换行并为视口预留对应高度。统计面板按可用画布缩放；中英日标签不经二次翻译，不使用动态字号动画。
