# 徽记与面朝下永久物 · 2026-09-30

## 实现

- 桥接导出双方统帅区的徽记，普通统帅区效果不冒充徽记。每个徽记保留独立对象 ID、实际规则文字、本地卡图图号。
- 战场左侧独立盾形徽记位置，不加入神器／结界叠放，悬停显示实际效果。
- 面朝下永久物使用本地牌背，显示引擎实际力量／防御力、指示物和公开关键词。显化、匿伏、变身、伪装共用展示和 0.32 秒翻面过渡；费用、守护、翻面条件、触发异能仍由 Forge 处理。
- 仅引擎允许查看的玩家收到原牌名称、图号和规则；只在悬停详情显示。对手不收到这些字段，观战投影明确丢弃它们。
- 保留不同盖牌的独立身份，不把同样外观的盖牌折叠合并。

## 验证

运行 `python Tools/ForgeBridge/Test-EmblemFaceDown.py`，结果见 `Tools/Validation/Reports/EmblemFaceDown/result.json`。

通过实际桥接输入执行：

1. 加鲁克 -6 异能结算，双方视图出现一个徽记，生物实际获得 +3/+3 与践踏。
2. 显化、匿伏在引擎布置后，通过优先权选牌、支付费用、展示确认翻回正面，对象 ID 不变。
3. Willbender 从手牌面朝下施放，再支付变身费用翻面。
4. Greenbelt Radical 从手牌伪装施放，盖牌有守护，支付费用翻面后实际触发全体 +1/+1 指示物。
5. Manifest Dread 实际施放并选择牌库顶两张之一；另一张进入墓地。选择地牌时仍成为盖牌生物，但不能按生物费用翻面。
6. 对手视图不含原牌名称／图号；己方可见。Unity 观战投影保留徽记和公开守护／践踏，不含原牌字段。

Unity 中载入真实引擎快照进行展示验证。翻面启动时旧牌背数量为 2、正面横向比例为 0；结束后旧牌背数量为 0、正面比例恢复为 1。通过调用实际悬停方法检查详情；未声称物理鼠标端到端验证。编译与运行检查无 Console Error。

本地 `TELD/19`（加鲁克徽记）、`TDSK/18`（显化辅助牌）、`TMKM/21`（匿伏辅助牌）读取结果均为缺失。没有下载或修改卡图／卡牌数据。徽记显示缺失卡图，盖牌使用已有 `Resources/UI/CardBack`；尚不是 Arena 的特殊盖牌插画。

测试覆盖上述代表机制与视图链路，不宣称全体徽记／所有特殊翻面效应穷尽验证。
