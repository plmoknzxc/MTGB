# 卡组文本交换与工具栏（2026-09-23）

## 已实现

- 顶部按钮增加实体底色、圆角描边和悬停反馈；卡组选择框缩至 220 参考像素，长名称限制在框内。
- 工具栏使用横向布局，搜索框占用剩余空间；加入「另存」「导入」「导出」。
- 另存复制当前编辑内容，原文件保留；同名（含文件名清理后的重名）自动追加编号。
- 导入无格式选项。打开导入框后粘贴，自动识别文本，成功即保存为新卡组并打开，没有成功确认弹窗。
- 未识别卡牌、指定版本不匹配、错误数量、不支持的分区等显示行号/错误；整份拒绝，不会悄悄丢牌或覆盖当前卡组。
- 导出选择 MO、MTGA、MTGB，预览并复制到剪贴板。

## 现有 MTGB 格式

`Decks/*.mdk` 是 UTF-8 纯文本，主键为「系列/收集编号」。

```text
#name Example
#main
36 10E/376
4 10E/232
!side
2 7ED/226
```

可选 `#commander` 存放指挥官。旧仓库也能读取 JSON 旧牌组，但本次粘贴交换使用现有 `.mdk` 行文本，未扩展旧 JSON 剪贴板。

| 格式 | 本次文本输出 | 版本信息 |
| --- | --- | --- |
| MO | `4 Shock`，空行分隔备牌 | 不保留具体印刷版本 |
| MTGA | `Deck` / `Sideboard`，`4 Shock (10E) 232` | 保留系列、编号 |
| MTGB | `#main` / `!side`，`4 10E/232` | 保留系列、编号及原生分区 |

MO 纯文本、带 `SB:` 前缀的行、MTGA 分区、MTGB 分区自动识别。数量重复累加，不擅自截为 4 张；赛制合法性仍由已有对局校验负责。

支持牌库中的英文卡名、已收录中日文译名、双面/连体正面名称及完整名称、字母收集编号。无版本信息按本地可用印刷版本稳定选取；明确指定的版本缺失时报告错误，可改为仅卡名后再导入。

目前 DeckDefinition 没有同伴标记字段，含 Companion 分区时明确报错。MO 纯文本导出含指挥官标记的卡组也明确报错，以免丢失分区含义。DIY 不能导出到 MO/MTGA，使用 MTGB。

## 验证

- `DeckExchangeValidation.RunCodec()`：三种格式往返、主备牌、原生指挥官往返、中日文别名、连体牌、字母编号、SB 前缀、重复行累加、超过 4 张不截断、错误整份拒绝。
- `DeckExchangeValidation.RunUi()`：真实主菜单 Play Mode，按钮点击区域，另存保留内容，粘贴 `.mdk` 自动创建并保存，错误不替换当前卡组，三种导出复制后再解析，原文件内容不变。仅清理该次唯一前缀的测试文件，并恢复剪贴板。
- 自由比例和 16:10 工具栏布局检查，按钮不重叠、不越界；Unity Console 无错误。
- 结果与截图：`Tools/Validation/Reports/DeckExchange/`。

本次没有启动 MO/MTGA 客户端做实机导入；格式转换通过本地测试，目标客户端仍必须收录相应卡牌和版本。不保证 Forge 全卡都能在 Arena 使用。本次也未重新打 Windows 独立包。
