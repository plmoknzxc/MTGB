# ON / AUTO / OFF 时点控制

战场右下方圆形按钮，按 ON → AUTO → OFF 循环，默认 AUTO。每个客户端独立选择，不改变对方的模式。

| 模式 | 优先权 | 法术力费用 |
| --- | --- | --- |
| ON | 引擎提供的每个窗口都手动让过 | 手动点击法术力来源或法术力池 |
| AUTO | 空堆叠的重置、维持、抓牌窗口自动让过；有堆叠时只在引擎判断有可响应动作时停留（包括自己的诱发）；无可响应动作的刺探等诱发自动让过，结算中的必要选择仍手动；保留自己的主阶段 | 调用 Forge 自动支付 |
| OFF | 所有优先权窗口自动让过 | 调用 Forge 自动支付 |

目标、弃牌、调度、攻击、阻挡及其他必须完成的规则选择不会被 OFF 擅自决定。独立的“自动／手动付费”按钮已移除。自动付费同一输入上下文仅尝试一次，失败后停留，允许手动补足或取消，避免循环重试。

实现中取消了桥接层无条件的对手回合自动让过，客户端通过 `ForgeControlPolicy` 提交服务器已经提供的合法选项；身份、过期请求和重复提交仍走原有 action gate 校验。规则引擎提供可响应状态及支付上下文 ID，不由 Unity 计算费用。

验证：`ForgeControlModeValidation.Policy()`、Play 模式下 `ForgeControlModeValidation.Ui()`；实际滑板咒语分别使用手动、自动付费，验证进入堆叠、选目标、结算；欧泊玛珂与呼魂取消回归。报告位于 `Tools/Validation/Reports/ControlModes`。
