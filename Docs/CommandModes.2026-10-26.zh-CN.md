# 指命模式缺项展示（2026-10-26）

用户截图中《寇安甘的指命》的四个模式只显示三个。实际原生施放复现：场上没有神器时，Forge `CharmEffect.makePossibleOptions` 删除第 3 个“消灭目标神器”，向桥接只交付原第 1／2／4 项。不是把三选二改成四选二规则，也没有放开没有合法目标的模式。

## 修正

共用普通／追欢模式回调现在补上原能力 `Choices` 中被原生剔除的公开说明，以 `mode:unavailable:<原序号>` 和 `disabled=true` 表示。可选项继续使用原 `possible` 的响应 ID、顺序与回调索引；真正返回给引擎的仍只是原生合法列表。若公开原列表不能覆盖本次原生候选，则沿用原候选，不遗漏动态增加的合法模式。

Unity 保留四项的原卡文顺序，禁用项灰显并注明“当前不可选”。原生接收入口已有禁用检查，三条缺目标流程都实际发送非法选项，收到 `invalid-option` 后仍能使用同一有效请求继续选择并结算。没有新增网络字段、协议号或卡牌脚本，未改可选性规则。重复模式／季节爪印的另一个回调没有改动。

## 证据

目录 `.tools/command-modes-1026/`：

- `before/result.json`：真实施放产生 3 项，原模式序号为 1／2／4，缺项展示门槛失败。
- `after/result.json`：5 条实际流程通过，分别为四项全可选的 1+3／2+4、无神器的 1+4、无坟墓场生物的 2+3、两类目标都缺失时的 2+4。包含真实支付、返回生物、弃牌、消灭神器、2 点伤害、重选及回到优先权；3 条实际禁用项拒绝。没有把这些场景扩大为全卡池效果证明。
- `ui-result.txt`：**PASS 462**。从上述真实原生请求重放到正式新场景，中英日、小／标准／大字号，全部四项及正文、禁用标识、确认门槛、完整 viewport、真实射线点击及准确回调索引均核对。UI 证据与原生效果证据分开，不冒充同一次公网操作链。
- `kolaghan-four-modes.png`：实际打开复核，四项均可见，第 3 项灰显。
- `mode-regression`：冻结脚本在 `Tools/Validation/Reports/ModeChoices` 产生的本批增量，旧已跟踪报告恢复原样，避免改写历史批次身份。只回归受影响的 `spree-targets`、`spree-rich`、`spree-limited`、`choose-one`、`choose-one-cancel`，5 条通过。更新 `spree-targets` 的旧断言，检查三项保留、原合法第 3 项仍可选、其余两项禁用，不把旧“只剩一项可见”当作新展示标准。运行环境显式启用生产按需卡库与 2 个 JIT 编译线程，原生规则操作未改。

首次非法选项注入后，测试驱动误等引擎重发请求而超时；`invalid-option` 本来就保留原请求，不会自动重发。原 FAIL 与 trace 保留在 `driver-failure`，修正驱动后只补失败的后三条，前两条成功流程未重跑。另有一次 Editor 不在 Ready Play 的 UI 准备失败；最终从 Main 正常初始化并确认正式语言资源 Ready 后完成。

机制清单只刷新分类，原 2,582 未登记／318 需重测状态保留。五个新场景为专项有界结果，不重置或恢复其他机制目标。
