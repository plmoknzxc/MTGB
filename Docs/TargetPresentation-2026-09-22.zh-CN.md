# 目标选择呈现

参考用户提供的 `MTG Arena_09-22-2026_3-53-44-666.mp4`，观察 03:50–03:59 连续取样，重点为 03:54 附近。

## 改动

- 待施放牌在右侧显示完整卡面，下方提供取消按钮（Forge 提供取消选项时）。
- 使用带光晕与箭头的蓝色贝塞尔弧线，合法候选吸附至卡牌/头像中心并加圆环。箭头不拦截点击。
- 合法候选继续使用 Forge 提供的选项；支持点选目标及从待施放牌拖到目标。提交/取消后隐藏箭头。
- 补齐箭头的 CanvasRenderer，避免有对象却不显示。
- 预览图从当前卡牌数据读取，避免刷新当帧读取等待销毁的旧 UI 卡面，同时兼容紧凑战场牌面。

## 验证

- `ForgeBattlefieldValidation.Run()`：真实 Forge/Unity 下地、闪电击、玩家目标、支付、双方让过、生命 20 → 17；非法目标、过期和重复提交检查通过。额外断言箭头实际生成曲线网格、待施放牌位于右侧。
- `TargetPresentationValidation.Run()`：合成展示状态，检查生物目标、空白/过期/重复操作拒绝、取消提交一次且清除箭头、预览卡图身份；输出 `Tools/Validation/Reports/TargetPresentation/creature-target.png` 和结果文件。这不是独立的真实生物伤害规则测试。

本次实现目标选择期间的视觉反馈，不包含结算飞弹、选完目标后持续显示的堆叠连线，也不声称覆盖所有多目标/分配伤害交互。
