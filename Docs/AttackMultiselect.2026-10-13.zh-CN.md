# 2026-10-13：宣攻多选与单独撤回

本批响应用户对全部攻击、多个待选箭头及共同攻击对象的要求。项目源码、本机桥接类已更新；未打包客户端、未部署服务器，不改变旧 goal 状态。

## 行为

- 点尚未分配攻击对象的己方合法生物，加入本地选择。每个生物保留自己的箭头；再点一个已选生物只取消这个本地成员。
- 拖动一个生物时加入／保留当前选择，不会把已有成员替换掉，也不会把拖动已选成员解释为取消。
- 点击玩家、旅法或战役，或者把箭头拖到其上，一次提交当前全部选中的物理 ID。高亮候选取所有成员的原生合法对象交集。
- 全部攻击仍攻击对手玩家，之后直接点击已分配的生物，提交它自己的原生 recall 选项，其余生物保持攻击。
- 新权威请求、离开宣攻、取消全部攻击清除本地选择。保留原生 banding 的独立选项；界面多选不是联合攻击规则。
- 客户端只对最终共同宣攻发一个回复，本地多选不等待网络。服务端及 Java 桥接分别检查同一请求内的合法攻击者、共同对象、去重和主选项成员；规则动作仍走 Forge InputAttack。
