# 原卡图与顶部动态费用

后续双组顺序、尺寸与纹理修补见 [双组费用增量](LegacyPairedCost-2026-10-08.zh-CN.md)。以下保留本批108项／45项的原范围和版本身份。

## 当前决定

默认恢复原扫描卡图。完整组件卡面、PSD 导出框架、字体、费用图标及其代码保留，供以后继续调整。游戏设置中的渲染切换已移除，旧的 `UI.ComponentCardFaces` 偏好不再决定模式。

代码开关位于 `Assets/Scripts/UI/GamePreferences.cs`：`DefaultComponentCardFaces = false`；当前运行时可调用 `SetComponentCardFaces(true/false)` 切换，发出既有刷新通知。子系统重置会恢复代码默认值。

## 费用显示

手牌、坟墓场及放逐的完整卡图采用 `LegacyCardCost`：原 Image 和原 sprite 保持，费用区域另加小块底色修补，使用同一张扫描图两侧背景生成并羽化边缘；动态费用符号排列在卡牌顶边上方，跟随卡牌旋转和移动。名称、插画、类别和正文沿用原扫描图。

费用取已有原生字段：手牌及该区域有使用许可的牌使用 `previewManaCost`；其他公开牌保留牌面费用。历险独立使用 `adventurePreviewManaCost`，顶边左侧为历险、右侧为本体。没有法术力费用的地牌不创建费用条，也不为该条预留空位。显示层不计算加减费、许可或扣费。

区域浏览为顶部费用预留空间；原生明确提供的施放按钮独立于卡面模式，并保留准确选项身份。暗置牌不展示费用。战场紧凑卡图、悬停原卡图和堆叠的既有分支不添加这条费用组件。

当前修补坐标覆盖普通纵向标题栏、历险和上移标题的旅法。战役正面、分割／余响、房间等独立旋转版式，以及无目录身份／无卡图，继续原来显示；未把普通标题坐标套到这些版式。本批没有穷举所有印刷和非标准展示框。

## 证据与限制

`.tools/legacy-dynamic-cost-1008/` 保存本批驱动、结果、实际 Unity 截图及生产源快照。

印刷抽样结果 `types-result.txt` 45项检查通过；截图已逐张查看。前版视觉残边另存 `first-types-*.png`，即使当时结构检查通过也不作为最终视觉结果。

最终显示／交互／重建结果 `result.txt`：108项通过。Unity 无 C# 编译错误，保留完整组件与原图两种模式切换证明。

费用和权限检查使用此前真实原生 `before-hand.json`，包括增加费用后的妖精幻视师、碎骨巨人和历险，以及有／无使用许可的区域牌；复用原生效果证明，本批没有新增引擎或联网结论。

局部检查包含：默认旧样式、忽略旧偏好、设置没有切换按钮、真实手牌同 ID 的费用刷新、主／历险图标身份、原 sprite 保持、中英日、本体和遮盖不拦截点击、暗置隐私、代码双向切换，以及坟墓场／放逐施放按钮的真实射线与准确原生选项提交。

印刷抽样另检查旧框反击咒语／阳光戒、旅法、传纪、十符号费用、双面正面、结界和无费用地。前版结构检查虽通过，截图仍发现旧框圆底和十符号费用留下残边；保留原截图并扩展修补边界、收紧长费用符号间距。截图检查与结构结果分别记录，未将结构 PASS 当成所有卡图的视觉验收。

驱动首次将宿主 Image 算入“不拦截点击”检查，第二次在新建组件完成布局前检查其适配结果，均保留失败并修正驱动。它们不属于原生规则失败。长期机制 goal 继续暂停，首验统计不变。

恢复可操作演示时发现卡面重建边界：`Clear` 延迟销毁旧子对象，按同名路径查找会拿到待销毁的旧 Face，费用条随之消失。改为缓存本次创建的准确 Face 引用；新增历史真实 `before-hand → stack-adventure → before-hand` 转换，并在延迟销毁完成后检查当前手牌费用。此前106项通过结果和消失截图保留，最终源另存 `final-source-snapshot`，没有覆盖原源快照。
