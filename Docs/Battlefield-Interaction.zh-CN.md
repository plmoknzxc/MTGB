# 战场交互改版（2026-09-22）

参考用户提供的 MTGA 录屏，取样 00:30–04:00 的对战与 01:22–01:30 的连续操作画面。仅参考布局和交互，没有从视频提取游戏美术作为资源。

## 当前实现

- IntegratedBattlefield 的手牌使用底部扇形重叠布局，不再分页；悬停抬起、放大、摆正，布局更新平滑补位。
- 卡牌对象按身份保留，收到优先权/状态更新时不再整批销毁。卡面内容仅在可见状态变化时重绘。
- 悬停结束按当前手牌顺序恢复遮挡层级，不再使用悬停前可能已失效的 sibling index；连续扫过相邻卡及更新快照后保持顺序。
- 单一法术力能力直接交给 Forge 执行；多个能力在来源卡牌上方显示菜单（包括地牌和生物），右侧不再重复显示。桥接提供来源编号；卡牌暂时离开原区域时保留点击位置，无卡牌来源的全局对话居中显示。
- 手牌拖动使用 Canvas 坐标，释放到中间战场才提交；拖回下方、拖到界面侧栏取消。仍保留点击出牌，且服从服务器候选、请求编号与重复提交保护。
- 进入目标请求后显示待施放牌和鼠标指向箭头，可点击候选或从待施放牌拖到候选；调度使用先保留、后放回的交互。付款、优先权及对应回归见 [CR 交互修正](CRInteraction-2026-09-22.zh-CN.md)。
- 按最新反馈，场上与手牌使用同一张完整卡图：保留原始名称、插画、卡框和规则区，移除自制灰色名称栏与插画裁切。横置仅轻微顺时针旋转、变暗和显示半透明箭头。
- 地牌宽度上限 112、生物上限 136，低于手牌 182；所有外框保持 182:254 宽高比，卡图用 preserveAspect 等比显示。战场悬停不放大。
- 场上不再使用 X/Y 三维旋转压缩牌面；未横置保持正直，横置仅在屏幕平面旋转 -12°。地牌行左对齐、紧凑排列。
- 同印刷、同展示状态的基本地/无规则文字生物可叠放并显示数量；同组基本地点一次直接操作一张。支付不会拆开双方地组；撤回后按实时状态重新归并。目标/攻防选择只展开含有效候选的组。
- 姓名和生命采用长方形面板：己方左下角，对方右上角；己方区域堆在面板上方，对方区域堆在面板左侧。左上角使用齿轮入口，打开与组卡界面共用的语言/字号设置，且对局中增加认输及二次确认。
- 主操作共用一个位置：自己回合、堆叠为空时显示“结束阶段”；对方回合或堆叠非空时显示“让过”。二者都提交 Forge 当前优先权的 OK，不强行跳转阶段；对手仍可响应，双方连续让过才由 Forge 推进。桥接不再暴露“让过直到回合结束”；可撤回法术力操作时单独显示“撤回”。

- 支付费用期间保留待施放牌的完整预览；堆叠使用 Forge 提供的来源卡牌及印刷标识绘制完整卡图，可点卡查看详情。

## 边界

现有 Forge 投影还没有完整提供指示物、贴附、临时获得的异能、召唤失调等状态。这版叠放用于归纳当前已同步的视觉状态，不代表牌在规则上完全等价；展开后每张仍有独立 ID。复杂永久物不自动归并，不能声称已完成 MTGA 全部表现。特效、指向箭头、音效、完整战场状态图标、移动端交互仍待制作。

主要实现：`ForgeBattlefieldController.Arena.cs`、`ForgeBattlefieldCardPointer.cs`。新布局在绑定场景时应用，现有场景节点及 Forge 接口保留。

验证入口：先在 IntegratedBattlefield 执行 `ForgeBattlefieldValidation.RunCombat()` 或 `Run()` 并等待结束，再在 Play Mode 执行 `ArenaPresentationValidation.Run()`。后者使用明确的展示测试数据，验证保留实例、叠放/展开、悬停、取消拖动、有效拖动、重复提交及 20 张永久物自动缩放。它不代替真实对局规则验证。结果及截图位于 `.tools/forge-migration/arena/`。


- 按 Z 提交当前 Forge 允许的 Undo；与撤回按钮走同一路径。不会调用支付取消或 End Turn。设置打开、输入框输入、非本人输入、请求已提交或没有 Undo 时不响应；Ctrl+Z 不触发。
