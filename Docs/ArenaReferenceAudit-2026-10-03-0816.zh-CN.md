## 一、地城：常驻入口、完整地图和下一房间选择

![05:25 地城地图中的合法房间](D:/project/MTGB/Docs/References/Arena-2026-10-03-0816/05-25-00.jpg)

录像中的三个形态应该分开：

1. **平时的进度入口**：左侧辅助状态列保留已进入的地城，可查看完整地图；它不占生物、地或神器结界的战场位置。
2. **第一次进入／完成后重新进入**：在合法地城之间选择。18:09 清楚显示普通探索的三张地图。
3. **继续探索**：放大当前地图，只高亮引擎允许的下一房间。选房间后，该房间的能力使用通用堆叠和对应交互，如占卜、选目标、产生珍宝或衍生物。

05:25 的两条分支、07:55 的三条分支、狂法师迷宫的整行宽房间，都说明不能只做几个等宽按钮。地图中需要稳定的房间 ID、合法下一房间及对应的点击区域。当前房间与合法下一房间用不同的视觉状态；不可走的格子不能提交。

20:10 的悬停布局是“来源牌＋完整辅助地图＋关键词说明”，辅助图顶部的黑色帽头和 `1/3` 是预览组的标题与序号。**预览有哪些相关地城，和游戏本次究竟允许进入哪张，必须独立处理。** 卡组编辑的辅助预览不能给对局添加第四个普通探索候选。

项目已有地城 Command 对象、当前房间文字及已完成地城列表；卡组编辑也已有地城辅助图。但当前战场 `PresentEmblems` 仍把地城和其他效果一起画成 120×82 小牌面，通用选牌渲染器则按卡牌候选和按钮布置。它们尚不能充当上面“地图中选房间、显示路径进度”的专项验证。

应补的边界：两个玩家各有地城、同一地城再次探索、最后房间尚在堆叠、完成后再进入、普通探索与探索幽暗地域的区别、先制转移、没有可继续房间的请求、相邻请求切换时旧房间点击失效。录像没有证明全部这些规则；先制／幽暗地域路径需另跑实际效果。

## 二、立传和登殿：条件进度与永久资格分开

![16:00 触发排序与左侧辅助状态牌面](D:/project/MTGB/Docs/References/Arena-2026-10-03-0816/16-00-00.jpg)

立传达成后获得的是“历世书传”，属于玩家资格。条件是控制带立传的永久物，并控制至少三个神器、传奇永久物和／或传纪；同一张传奇神器只计一个永久物。获得后即使来源或用于达成条件的牌离场，资格仍保留到本盘结束。[官方立传机制说明](https://www.magic.wizards.com/en/news/feature/the-hobbit-mechanics)

登殿获得“城市祝福”也是保留到本盘结束的玩家资格。只有十个永久物、却没有带登殿的永久物或正在结算的登殿咒语，并不会自动获得祝福。[官方登殿说明](https://magic.wizards.com/en/news/feature/modern-horizons-3-mechanics)

两者可共用玩家资格展示，但门槛、计数范围和给予的收益不同：

| 项目 | 立传 | 登殿 |
|---|---|---|
| 条件进度 | 符合类别的永久物数／3 | 你控制的永久物数／10 |
| 获得后的玩家资格 | 历世书传 | 城市祝福 |
| 来源离场后 | 已获得的资格保留 | 已获得的资格保留 |
| 本段直接可见 | Óin 当前 2/3、敏捷和独立辅助牌面 | Ocelot Pride 的 6/10、21/10 徽标及独立辅助牌面 |
| 展示不能做的事 | 把传奇神器当两个对象、把资格当生物关键词 | 把超过门槛的进度强行截成 10/10、因数量降低删除祝福 |

**立传不等于传纪章节。** 历世书传是已获得的玩家资格，镜割寓言是战场上的传纪，地城当前房间又是第三种进度。可复用标题、徽标、说明和展开容器，但不能共用同一份状态值。

录像的左侧辅助列同时容纳城市祝福、历世书传和地城。我们的界面可以沿用已经讨论过的己方头像上方／对方头像下方位置；关键是普通状态可辨认，多个状态不会隐藏，展开能看详细信息。录像没有要求必须照搬 MTGA 的屏幕左边位置。

本次通过了自然达成条件和来源移除的状态检查，没有手动调用 `setBlessing(true)` 或 `setEnduringStory(true)` 来替代资格获得。另核对了桥接：双方视角都收到同一个资格对象 ID，来源移除后 ID 不变，不生成重复标记，资格属于正确玩家。

界面仍要补：进度徽标、首次获得反馈、资格常驻入口、两个玩家同时获得、与魔戒／地城／多个延迟效果同时出现、换盘清理，以及三语言／字号检查。已有“手动设置特殊状态后能导出”的夹具，不等于这些自然条件和界面行为全部通过。

### 土地类别的复核范围

“全种类地”需要先拆成相互重叠的特征。以下是本次夹具中的代表牌；不是宣称卡池每一张地的所有组合都已验证。

| 特征 | 检查代表 | 本次确认的边界 |
|---|---|---|
| 五种基本地 | Plains、Island、Swamp、Mountain、Forest | 具有“基本”超类别的地不受红／蓝月影响；树灵作用于己方时赋予五种类别与产费 |
| 雪境基本地 | Snow-Covered Forest | 基本与雪境保留；不按名字中有“Forest”推断效果 |
| 雪境非基本地 | Scrying Sheets | 仍非基本，雪境保留，当前产费随效果改变 |
| 找地地 | Wooded Foothills | 自己和对方都在快照中；移除效果后类型恢复，当前有效能力另有记录 |
| 自带基本地类别的非基本地 | Breeding Pool | 有 Forest／Island 不等于基本；可被红／蓝月改变 |
| 传奇地 | Minamo, School at Water's Edge | 传奇保留，仍非基本 |
| 神器地 | Darksteel Citadel | 神器类别保留；不能把所有非基本地重画为普通基本地 |
| 可变生物的地 | Hive of the Eye Tyrant | 未激活状态下的类别和产费；已激活后的效果持续期本次未测 |
| 本身就是生物地 | Dryad Arbor | 生物身份保留；当前是否生物决定战场行 |
| 结界传纪地 | Urza's Saga | 结界／传纪身份保留，章节失效与状态动作另测 |
| 对方地与己方树灵的范围 | 对方 Wooded Foothills | 月亮影响双方；己方树灵不能给对方赋予五种类别 |

本次六组层次配置：红月、蓝月、红月→蓝月、蓝月→红月、红月→树灵、树灵→红月。每组预置 15 个地对象，检查有效类型、产费、保留的超类别／牌类别、桥接 `currentType` 和移除后的类型恢复。
