# MTGB 卡牌资料维护规范

当前客户端读取 `ForgeRuntime` 中的官方印刷目录和 Forge 规则脚本。多语言卡文、搜索资料和图片关联索引位于 `Assets/StreamingAssets`，卡图位于本地 `CardImages`。数据格式与生成入口以 `Tools/ForgeBridge` 中对应脚本为准。

## 印刷身份与来源

- 使用系列代码、收藏编号和牌面身份精确匹配；保留双面牌、分割牌及其他多部分牌的关联。
- 官方规则以固定 Forge 版本的脚本为准；文字翻译和卡图属于展示资料，不能替代实际规则。
- 导入翻译或图片时核对牌名、系列、编号和牌面。相近名称、不同印次和勘误前图片不能自动当作准确匹配。
- 文本使用 UTF-8。导入记录保留来源、匹配结果和无法确认的缺口。

## 修改与校验

1. 先完整阅读对应导入脚本和目标格式，确认本次修改涉及哪些语言、印刷版本与牌面。
2. 在工作副本生成资料；确认格式、身份、重复记录和文件完整性后再替换目标文件。
3. **数据校验**：检查序列化格式、精确匹配及索引关联。图片检查解码和尺寸；翻译检查名称、类别、规则文本及多面字段。
4. **运行验证**：用 Unity 实际加载修改后的资料，检查语言切换、卡牌详情、关键词、衍生物和辅助图；修改规则或桥接字段时，还须通过真实 Forge 会话验证相应费用、目标和结算行为。
5. 记录通过项和未验证项。导入成功、目录可加载与对局行为通过是不同的检查结果。

## 本地图片

卡牌和机制辅助图在运行时读取本地文件；缺失时显示缺图提示。异画选择界面的预览按其独立流程处理。精确目录、导入命令和语言回退规则见 [卡图说明](CardImages.zh-CN.md)。卡图包保留在本地，Git 中保存导入工具与必要索引。
