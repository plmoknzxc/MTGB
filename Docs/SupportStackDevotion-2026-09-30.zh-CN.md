# 神器／结界折叠与献力显示

## 实现

- 可合并的同版本、同状态非生物神器／结界使用错位卡图叠放与数量标记。
- 横置、指示物、类别、关键词、拥有者等投影状态不同则分组不同。
- 桥接层对附件、关联放逐牌、记忆／压印、选择记录、改写异能和已有启动记录采取保守策略，不折叠。
- 点击可启动的折叠组先展开；选择目标／卡牌时展开候选组，不替用户选择其中一个对象。
- 神牌的献力取自 Forge 静止式异能的 CheckSVar 与门槛；支持 Devotion 与 DevotionDual。战场和悬停大图显示当前值／门槛。
- 献力不足的类别变化显示在悬停类型栏，保留原始状态查看入口。

## 验证

`python Tools/ForgeBridge/Test-FraMechanics.py comparison`

真实引擎夹具预置永久物，随后实际以兆临施放霸主：

- 海神 1/5，非生物。
- 欢宴之神 5/7，非生物；霸主进场后 7/7，成为生物。
- Unity 中 3 个阳光戒折叠一组，2 个辉煌颂歌折叠一组，背层使用实际卡图。
- 点击阳光戒组展开 3 张；UI 目标选择测试视图也展开 3 张。
- 两个献力徽标和悬停献力字段与引擎值一致。

截图：`.tools/fra-mechanics-ui/stack-devotion.png`、`devotion-hover.png`、`devotion-active.png`。

此处是规则引擎测试加 Unity 快照交互验证，不是双客户端联机测试。不同版本卡图暂不合并；复杂关联对象保守分开。献力徽标当前针对有献力门槛的持续效应，不涵盖所有在结算时使用献力的咒语。
