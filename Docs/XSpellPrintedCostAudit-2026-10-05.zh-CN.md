# 保留卡图的 X 与施放费用复核

## 当前决定与实现

按用户最新决定，普通 X 咒语只重绘下方规则文字，顶部完整保留原卡图费用的 X／XX，不再把它替换为数字，也不再创建 CostRegion。规则文字沿用 Omen 的14基准字号、浅色底板、滚动与独立蓝色 X。文本底板上沿从0.396降到0.369（现代常规卡框的相对牌高），位于完整类别栏下方；名称、插画、类别栏、印刷费用、卡框与页脚均来自完整原图。长规则不压缩，滚动看完。没有修改本地卡图、翻译或 Forge 费用计算。

X 是宣布的规则变量，费用是实际施放法术力要求，分别记录。旧桥接 `source.manaCost` 仅将印刷费用的 X 替换为数值，并不包含外部加减费。新增 `source.castingManaCost`：固定 Forge 的 PlaySpellAbility 在 CostAdjustment.adjust 之后、消耗法术力之前保存的费用快照。结算中的 effect 付款不覆盖它。Unity 优先使用新字段；历史快照缺字段时回退旧值，不把这种兼容展示计为加减费验证。详情费用同步使用新字段。

此记录不改变规则费用、法术力值或 X，也不从总耗蓝量反算 X。实际施放费用仍由 Forge 合并、加减；普通卡面上方现在显示原印刷 X／XX，规则框仍显示宣布的 X=几。动态副牌面／详情等既有消费者保留 castingManaCost；反击咒语要求补交的费用不追加到原施放费用。
