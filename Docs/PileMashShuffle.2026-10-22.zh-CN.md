# 十堆分牌与插洗（2026-10-22）

本轮依据用户澄清：大切是上5堆下5堆、逐张发完收拢，随后插洗3次；不做分堆时插洗至少7次，另外也会两叠换位切牌。此前把大切理解为单纯切牌不准确。

## 当前行为

默认模型 `physical-pile10-mash3-cut-v2`，替代五次交错v1：

1. 将当前牌库逐张循环发至10堆；每堆后发的牌在上。
2. 固定依上排左到右、下排左到右收回，第一堆作为最终牌库的顶端。
3. 插洗3次：每次在半数左右10%的范围分成两叠、交替插入1～3张的小段；每叠内部保持顺序。
4. 随机在非空位置切牌一次，将两段整体换位。

收堆顺序、分叠偏差和1～3张牌包是明确的模拟假设，不代表已测量用户的具体手法。算法只接收列表和随机流，不读取地牌、牌名、费用、输赢或起手内容；没有筛选/重抽起手，也不在末尾追加均匀置换。有限次数仍可能保留连张。

此默认模型进入所有原生 `Player.shuffle` 调用，包括开局、调度、找地与其他效果洗牌。局部“随机顺序放到牌库底”等原生动作没有被改写。用户此前选择的“不洗切”房间仍按保存顺序；回调计算的排列被保序入口舍弃，可能消耗随机流，但最终牌库不变。0/1张无需操作；审计中的次数是正常模型配置，不是声称短牌库也执行完整动作。

“不分堆＋7次插洗＋切牌”本轮作为另一种用户描述手法的原生对照，未新增客户端选项，也不随机在两种手法间选取。以后如需改默认手法需据明确行为决定，不看抽牌结果择优。
