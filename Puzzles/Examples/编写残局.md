# 用 JSON 编写残局

将同目录的 `clear-and-protect.json` 复制到上一层 `Puzzles`，修改标题和内容，再进入游戏的残局列表。也可以从列表导入任意位置的 JSON。每个 UTF-8 文件是一关。游戏写出的文件使用版本 3，已有的版本 1、2 可以继续读取。

在支持 JSON Schema 的代码编辑器中，给放在 `Puzzles` 下的关卡加上 `"$schema": "./Examples/puzzle.schema.json"`，即可补全字段、区域名和比较方式，同时提示拼写或类型错误。游戏本身可以离线读取这些文件。

新建残局时，游戏会把当前玩家名写入 `author`。手写关卡也可以填写 `"author": "你的玩家名"`。导入和再次导出都会保留原署名。自制和导入关卡在详情中显示作者，旧文件省略这个字段时显示「未署名」。

## 胜利目标

`turns` 从开局的第 1 回合开始计算，双方回合各算一回合。可填 1～30，默认 1。

| goal.mode | 通关时机 |
|---|---|
| `win` | 在指定回合清除步骤前赢得对局 |
| `survive` | 存活到下一回合维持步骤，或提前赢得对局 |
| `all` | 在期限内同时满足 conditions 中的全部条件 |
| `any` | 在期限内满足 conditions 中的任一条件 |

组合目标在开局就绪、每次将要获得优先权的稳定局面检查。一次咒语的各段结算完成后一起判断。若致命伤害直接结束对局，也检查最后局面。普通对局胜利时仍须满足题目，失败或平局按挑战失败结算。

若题目还要求赢下对局，可在 `goal` 中加上 `"checkAt": "win"`，仅在限时内获胜的时候检查全部或任一条件。选择 `"checkAt": "survive"` 则在存活到指定回合结束后的第一次维持步骤，或提前获胜时检查。省略时使用 `"state"`，局面一旦符合便通关。

每项条件用 `player` 指定 `you` 或 `opponent`，用 `op` 指定 `atLeast`（至少）、`atMost`（至多）或 `exactly`（恰好），`value` 为非负整数。

| metric | 检查对象 |
|---|---|
| `life` | 该玩家当前的生命 |
| `damageTakenThisTurn` | 该玩家本回合实际受到的伤害。回复生命不扣除累计伤害，支付生命不增加伤害 |
| `cardCount` | 指定区域中的牌数。必填 `zone`，可同时用 `name` 和 `cardType` 过滤。衍生物也按张计数 |

例如，下列目标要求对手在同一回合受到至少 3 点伤害，而且你的生命仍至少有 10 点。

```json
{
  "mode": "all",
  "conditions": [
    { "metric": "damageTakenThisTurn", "player": "opponent", "op": "atLeast", "value": 3 },
    { "metric": "life", "player": "you", "op": "atLeast", "value": 10 }
  ]
}
```

一组可放 1～32 项条件。战场数量按当前操控者计算。按英文牌名计数时，同名的不同实体都算在内。类别可填 `Creature`、`Land`、`Artifact`、`Enchantment`、`Planeswalker`、`Battle`、`Instant`、`Sorcery`、`Kindred`。

## 开局与牌张

填写 `version: 3`、`title`、`goal` 和 `cards` 即可开题。双方默认 20 生命，我方先行，从战斗前主阶段开始。`humanLife`、`aiLife`、`firstSide` 和 `phase` 可覆盖默认值。可选阶段有 `MAIN1`、`COMBAT_BEGIN`、`MAIN2`、`END_OF_TURN`。

每行牌使用英文卡名 `name`，数量 `count` 默认 1，`side` 默认 `you`。区域 `zone` 可填 `battlefield`（默认）、`hand`、`library`、`graveyard` 或 `exile`。战场牌还可填写 `tapped`、`summoningSick`、`damage` 和 `plusCounters`。

要指定进场顺序，在顶层设置 `orderedBattlefield: true`，按进场先后排列战场牌。同批进场的牌使用相同的正整数 `entryBatch`，不同批次按首次出现顺序排列。结附或摆位也可以先用游戏编辑器制作一次再导出，保留对应的 `key`、`attachedTo`、`targetCopy` 和 `tablePlace`。
