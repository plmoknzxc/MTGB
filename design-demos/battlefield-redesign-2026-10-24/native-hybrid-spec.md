## 本轮：手牌展开／下沉与右侧上移

用户明确允许展开手牌遮住战场：默认手牌从逻辑 y=813 上提至 690，露出完整牌面；点击战场中的牌或背景会下沉到 813，点击手牌重新展开。仅悬停不会把已下沉的整排手牌抬起。两态间使用短过渡动画；各类右侧按钮、详情与历史操作不会收起手牌。

堆叠顶部由 172 上移至 32，详情／历史由 433 上移至 293，阶段操作由 753 上移至 696。堆叠最左边界专门避开对方法术力翻页按钮；不能只检查法术力数值区域的根矩形。

自己的法术力池固定在 (1190,646)，保留左右翻页按钮及五种可见法术力，不跟随手牌。底图由同一 Unity 投影额外隐藏 `ManaPoolChips` 后截图取得，独立法术力显示从原生完整截图做 CSS 裁切（含左右各 32 单位的翻页空间），未修绘或生成图标。该区域仍是原型中的静态截图，未声称翻页或支付已接入。

本轮实际操作验证：1600×1000、1280×800 下点击战场收起、点击手牌展开；两态法术力矩形完全一致。较小窗口下沉手牌与全部原生卡牌热点交叠数为 0；两态均不挡法术力。最右手牌的悬停放大也避开法术力。对手原位法术力及翻页区不与上移的堆叠相交。浏览器无错误，Unity 恢复 Main 干净编辑状态；本轮没有再改生产 C#。

## 原生布局发现与修复

1. 普通地牌遗漏了左侧信息避让；旧图 `YourLands:20019` 实际压到自己的指示物与全局昼夜标记。满场滚动排布原先已有部分避让，但普通路径没有。现在两条路径共用左侧边界，边界包括玩家面板、指示物、信息牌与翻页按钮；普通路径按横置后的实际足迹平移牌列，保留原卡牌样式。
2. 神器／结界与旅法、战役同时存在时，原来总是为神器预留两行，再按四行统一缩小。旧实际宽度只有生物的 41.3%。现在多类别共存时每类先用一行及横向滚动，再按真实牌面、阴影和忠诚／防御标记足迹适配半场高度。单独神器恢复正常宽度。
3. 第一版按估算高度适配失败：战役越过中线约 27.28 个逻辑单位。已改为测量真实区域高度。保留旧失败说明，不把第一次候选记作通过。

源代码调整限 `ForgeBattlefieldController.Arena.cs` 的普通排布避让与落位信息、`ForgeBattlefieldController.DenseField.cs` 的左侧边界及辅助永久物尺寸适配；此前召唤失调展示等已有改动保留。

## 实际验证

`support-size-validation.json`：8 组实际 Unity 投影，1058 个断言通过。包含单神器、三种辅助永久物、每类一张、从混合场面恢复单神器、完整组合、拥挤横滚、大量地、多延迟标记；双方地牌不与左侧信息根矩形相交，各辅助区域不跨中线且互不重叠。最小辅助宽度为生物宽度的约 71.4%，单独神器为 100%。

`qa-native-protected-geometry.json`：重新截图后，所有记录的常态地牌与左侧信息不相交，下沉手牌／堆叠／详情历史／阶段 UI 不与记录的原生保护区域相交。当前展开手牌按用户明确要求可以遮挡战场，法术力单独避让。

前一轮浏览器检查 1600×1000、1280×800 两种窗口；当时手牌常态只占底部预留带，本轮已按上面的明确要求调整。黯潮龙侯放大原图显示印刷费用 5UU，当前费用另显 UU。详情／历史标签切换、历史悬停不抢回详情、点击历史卡回详情、暂停固定文字按外观切换、手动→自动→略过均已实际操作。无浏览器错误。

以上是局部显示／布局验证，不是 Forge 效果、网络、优先权或任意数量／任意分辨率保证。未扩大规则回归范围。Unity 已退出临时播放，恢复 Main 编辑场景，场景无未保存更改；没有修改正式场景资源、构建客户端、更新服务器或上传 Git。
