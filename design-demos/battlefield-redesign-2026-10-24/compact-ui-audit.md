# F：长堆叠与紧凑操作区增量

用户要求：缩小下方 UI，暂不展示详情／历史；右侧上方只保留可向下延长且超过可视高度滚动的堆叠；核对撤回和其他选项会不会占到法术力位置。

## 已调整

- 暂停显示详情／历史栏。原生战场、玩家信息、标记与地城维持上一轮。
- 堆叠固定可视长度 554 个逻辑单位，内部可视列表 520；标准字号下 1～4 项无需滚动，5 项开始滚动，空堆叠整栏隐藏。大字号、长说明按实际内容高度产生滚动。保留敌我颜色、来源与目标高亮，不在战场堆叠牌名上添加“堆叠几”。
- 阶段字号 23→19，回合文字 12→10，主操作按钮高度 43→36。操作内容按原生状态替换，不叠加多份“下一步”。三按钮允许分两行；数值与加减、确认／取消分两行，十位数不挤压按钮。
- 三个纵向区间独立：法术力 y=612、撤回 y=659、阶段／操作 y=694。撤回仅在对应优先权状态出现。所有操作区域均在展开手牌的右侧。
- 保留点击战场下沉、点击手牌上浮。悬停放大图仍避开法术力。

## 源码核对

`ForgeBattlefieldController.Integrated.cs` 创建 `UndoMana`，原生实际矩形为 (1387.88,684.87,92.24,24.71)。它是 `CornerCluster/ControlRow` 的子物体，不能因原截图没有出现就漏掉。

`Payment`、`HandActions`、`ChoiceActions`、`LandChoices.PresentNumericChoices`、`AttackBatch` 共用阶段下的操作槽。目标来源牌预览、中央支付／选择说明，以及 `CardSelection`、`PileSelection`、`AbilityOrder`、`DamageAllocation`、模式／进场／产费选择、调度走其他窗口或浮层。本轮分别采样，不把所有选项当成“下一步”。

图服务 `index_status`、`search_graph` 与两次相关路径覆盖检查持续返回 Transport closed；以上按准确源文件与当前 Unity 运行投影核对，未作图谱或项目全量覆盖声明。

## 证据与边界

`action-ui-manifest.json` 冻结 23 份输入及其来源：19 份既有实录请求、1 份明确的组合展示场面、3 份明确的适配器（撤回、大数值、数值＋取消）。`native-action-ui.json` 记录当前 Unity 三语投影，共 69 份当前布局、按钮文字／可用状态、矩形与活动窗口。输入只被展示，没有重跑规则效果，也未核销机制事项。

23 类状态包含普通优先权、撤回、支付、非瑞克西亚生命支付、手牌确认／重选／取消、X 数值、能量、宣攻、阻挡、目标确认、搜寻、坟场、对手手牌直接选择、卡牌排序、异能排序、加码模式、分堆、进场选项、产费选项、调度、分配以及两个数值边界。完整来源与适配器身份以清单为准。

新 HTML 操作区完成 276 个布局核对：1600×1000 下 23 状态×三语×三档字号（0.85/1/1.3）=207；1280×800 下三语大字号再核对 69。包含当前操作、数值、撤回、暂停与模式按钮的文字溢出、按钮相互交叠、窗口边界及与法术力交叠；非模态原生提示／目标预览也核对与这些操作区域的关系。原生窗口在原型中使用中文静态截图；这部分不能记作新窗口三语／字号功能测试。

堆叠检查 0/1/2/4/5/12/30 项；数量与渲染项一致，5 项起滚动。30 项滚动终点 2634/2634；鼠标滚轮移动 680。滚动到底后选择第 11 项来源，保持一个选中条目和一个“天空之怒”目标高亮。压力场面是明确的布局样本，不是真实施放了 30 个咒语。

较小窗口再次核对手牌下沉：与原生卡牌热点交叠数 0、与法术力不交叠，重新点手牌可展开。几何证据见 `qa-native-protected-geometry.json`；新交互、滚动、字号和控制台结果见 `qa-compact-actions.json`。

首次压力切换失败（原渲染器被闭包封装，外部脚本调用不到）记录在 `qa-compact-failure-stack.json`。已通过窄接口 `updatePreviewStack` 修正，重跑布局与滚动后无新增控制台错误；没有拿失败批次授予清洁运行结论。

本轮完成的是新右栏影响到的对局布局及静态窗口对照。HTML 操作按钮和原生窗口截图不连接引擎；这不证明设置、录像、局间流程、统帅区域页签或所有真实客户端交互已在新方案中接入。正式 Unity UI 集成与实战回归仍需另作验证。没有新增生产 C#、资源场景或规则引擎改动；Unity 已回到 Main、非播放、无编译、场景干净。
