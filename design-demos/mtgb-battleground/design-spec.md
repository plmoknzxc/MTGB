# MTGB 视觉方向预览规格

本轮预览的目标不是为现有深绿色界面简单换一组色值，而是验证 MTGB 作为一款以 Battleground 为核心概念的卡牌对战项目，应该拥有怎样的视觉身份。三版预览必须使用相同的信息架构、相同文字和相同 1920×1080 输出尺寸，确保比较的是设计系统而不是内容差异。预览页面统一包含 MTGB 字标、BATTLEGROUND 副标、联机对战、卡组编辑、游戏设置三个入口，以及极少量真实项目语境信息。不得编造玩家数量、胜率、赛季数据或社区评价，也不使用与游戏无关的库存照片和装饰图标。

第一版“曜石竞技场”强调即时对抗和现代竞技感。它应使用曜石黑、枪灰、冷白作为中性色，用蓝色和红色分别表达对峙双方。几何结构来自战场分区、部署线和阵营切面，但不能堆砌雷达、坐标、扫描线等廉价军事 HUD。按钮采用清晰的几何切角与高对比文字，主要入口由冷蓝承载，红色作为对手和危险状态的第二阵营色。该方向应最适合延伸到联机大厅和实际对战 HUD。

第二版“奥术典藏”强调卡牌、规则和历史感。背景使用午夜蓝黑，文字使用纸张般的暖白，辅以克制的旧金和深酒红。版式应像一本被打开的对战典籍：有严谨的细线框、章节编号和大号衬线字，但不要加入假羊皮纸纹理、魔法粒子或俗套发光符文。它需要比第一版更安静、更精致，同时仍能通过对称结构保留双方战斗关系。

第三版“现代桌游”采用明亮的暖灰纸面、墨黑正文、钴蓝和朱红阵营色。它应像高品质实体桌游的规则册与组件包装：平面、清晰、排版主导，几乎不依赖阴影和材质。界面要在一米左右的桌面显示距离下依旧易读，按钮和标题之间保持充足留白。该方向最适合卡组编辑和规则阅读，但与暗色战场的衔接成本最高。

三版都不需要内容型图片，抽象战场几何只作为结构元素。正式生产若选择其中一个方向，再补充 MTGB Logo、主菜单关键视觉和统一功能图标；本轮不让缺失素材妨碍对颜色、排版、层级和组件语言的判断。

## 已选方向：曜石竞技场

曜石竞技场已确定为 MTGB 的正式 UI 基础方向。生产界面使用 `#070A0F` 曜石底、`#11141B` 枪灰面板、`#EDF2F8` 冷白正文与 `#8995A9` 次级文字；玩家阵营使用 `#4285F4`，对手阵营使用 `#DC3C5A`。大面积蓝红只用于表达双方空间或主操作，普通容器保持黑灰，避免把界面做成霓虹 HUD。

开始界面的 Logo 区必须保持为独立的 `StartLogoSlot`，当前 MTGB 字标只是可替换内容，未来可直接换成正式图片或 Prefab，不影响菜单布局。开始界面不保留原预览中左上、左下和右下的说明性小字。联机大厅、卡组编辑、设置与对战 HUD 共享同一套颜色、细线框、按钮状态和阵营语义；卡牌自身的五色与插画不受主题重染。
