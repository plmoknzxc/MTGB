## 2. 屏幕骨架（1920×1080 基准，全部镜像对称）

```
0    ─ 对手 UI 带（高 200）：身份牌(右上) + 对手手牌(上中) + 对手三区堆(右下贴桌沿)
200  ─ 远端桌沿 FAR EDGE（1–2px，红方微光）
202  ─ 桌面区：对手战场排 → 中线 → 己方战场排；右缘为堆叠列
878  ─ 近端桌沿 NEAR EDGE（1–2px，蓝方微光）
880  ─ 己方 UI 带（高 200）：三区堆(左上贴桌沿) + 手牌(下中) + 右下角操作簇
1080
```

硬性规则：
- **左右无边界**（只有暗角渐变，不是边框）；**上下有桌沿**，两条桌沿样式一致、色温相对（近端蓝微光、远端红微光）。
- 上下 UI 带高度使用**同一常量（200）**，镜像布局，任何一边改动必须同步另一边。
- 结构总表：`对手带（身份牌右上+手牌上中+三区堆右下）→ 桌面 → 己方带（三区堆左上+手牌下中+操作簇右下）`。

## 3. 环境层（战场背景，可整体更换）

环境层是**独立的一层**，只含背景，不含任何卡牌/HUD 逻辑：

1. 桌面底色：纵向渐变（远端暗 `#0B0F17` → 中部 `#111725` → 近端 `#131A29` → 底部收暗），叠加极淡横向磨痕纹理（opacity ≈0.05）。
2. 氛围：左下玩家蓝光晕（rgba(66,133,244,.11)）、右上对手红光晕（rgba(220,60,90,.06)）。
3. 左右暗角：`rgba(3,5,8,.55)` → 透明（9% 处），不是边框。
4. 双桌沿 + 桌沿内外压暗带（`oppzone`/`handzone`）。

**换肤 = 只换这一层**。Unity 实现：地面用一块材质/贴图（或材质小包），做「战场皮肤」内容包；卡牌、HUD、规则逻辑零感知。已验证两套皮肤（曜石/熔木）仅换此层。

## 4. 透视（相机）

- 预览 CSS 参数：`perspective(1700px) rotateX(19°)`，变换原点 `50% 60%`。
- 换算 Unity：**俯角约 30–35°、FOV 45–50 的透视相机**看桌面平面。
- 验收标准（唯一的硬指标）：**对手排牌的屏占宽度 ≈ 己方同排的 0.85–0.90**。不追求更强透视（0.7 曾被否），也不要完全无透视（1.0 曾被否）。
- 建议双相机：透视世界相机渲染桌面卡牌；HUD 用 Screen Space Canvas（或第二正交相机）叠加。
- 手牌、HUD、检视面板、堆叠列都是**屏幕空间 UI**，不随桌面透视倾斜。

## 5. 战场排（数量无上限的摆场规则）

- 排序（从各自桌沿向中线）：**地排（远）→ 非地永久物 → 生物排（近中线）**；双方镜像。
- 卡牌基准尺寸 **92×128**（比例 0.72），圆角 6，间距 7。
- **密度规则（爆场）**：一行超过可用宽度 → 加大重叠（参考值 -16px/张）→ 仍超则整行等比缩小；一行不够再起第二行。每侧每类最多两排，再多继续压缩。
- 横置 = 桌面内旋转 90°，散布在排中（不集中在一端）。
- 有图卡用真实卡图；无图卡用「生成模板卡」（结构化：名牌/法力费/色框/类型行/规则文本行/攻防角标），禁止退回扁平色块。
- 中线：2px 红→银→蓝渐变 + 中央菱形 10px + 轻辉光（用户明确要求可辨识）。

## 6. 手牌

- **己方**：底部居中扇形，卡 124×173，重叠 -30，扇角 ±9°，下沉弧度 0–2px；悬停上浮 38px、放大 1.14、蓝色描边 + 蓝色辉光。
- **对手**：顶部居中扇形卡背，卡 78×110（≈己方的 63%，勿再缩小），扇角 ±12°，压暗（brightness .45–.5 + 降饱和），右下角数量圆标（如 7）。

## 7. 堆叠列（右侧，MTGA 式）

- 位置：桌面右缘内侧（预览 right:70，垂直居中于桌面），宽 172。
- 结构：标题「堆叠 STACK · N」→ 堆叠项（最新在最上）→ 溢出尾项「+N 项 · 滚动查看」。
- 堆叠项：44px 高横条 = 左侧迷你卡背图标 + 名称 + 类型/费用；**当前结算项**蓝色边框 + 右侧「结算中」小签。
- 交互：**点击/悬停 → 左栏检视面板放大**；多项时 ScrollRect 拖动滚动（用户已确认接受此方案，MTGA 同款：右侧叠放、点击查看）。

## 8. 区域堆（牌库/坟场/放逐，双方各一组）

- 组件：横排 3 只小堆，每只 54×74；牌库叠真卡背，空堆用虚线斜纹框；右下角数量签（如 51），下方 8.5px 标签（牌库/坟场/放逐）。
- 位置（镜像）：**对手组**右上、身份牌正下方（top 96）；**己方组**左下、身份牌正上方（bottom 124）。
- 交互：**点击 → 打开浏览详情视图**（列表/扇形展开，逐张可翻）。⚠️ 浏览视图尚未设计，实现前需补一张交互稿。
- 用户已权衡过「放右缘」并否决（右缘要让给堆叠列）；「放名字框上方遮挡问题」已通过横排+上下错位解决。

## 9. HUD 组件明细

### 身份牌（双方镜像，330×76）
- 六边形头像框 46px（己方蓝/对手红渐变）+ 名字 15px + 阵营微标签 + LP 大数字 30px（己方 `#BFD6FF`/对手 `#FFB3C0`）。
- 位置：对手 `right:52, top:16`；己方 `left:36, bottom:20`。左缘 4px 阵营色条。

### 右下角操作簇（仅己方，两行右对齐）
- 第一行：**法力池**「可用法力」+ 色凑圆片 17px。
- 第二行：**回合徽章**（小六角 56×50，内为大号回合数 + TURN 微标）+ 阶段文本（「第一主要阶段」+「回合 4 · ROUND 4」）→ **计时环** 40px（蓝弧 + 0:47，副标「决策剩余时间 DECISION TIMER」）→ 竖分隔线 → 「跳过战斗」圆钮 62 → 「结束回合」主圆钮 78（蓝环 + 辉光）。
- **当前阶段直接由徽章/文本显示**，无相位菱形条（已被否决删除）。
- **优先权徽标**：蓝底细框小药丸（脉冲圆点 +「你拥有优先权」），悬于操作簇上方（bottom 158）。对手回合变红底「等待对手 · 对手拥有优先权」。

### 左栏检视面板（262 宽）
- 结构：顶部蓝条 + 「检视 INSPECT」+ 来源编号 → 卡图（338 高，真实卡图优先）→ 名称 + 费用圆片 → 类型行 → 规则文字 → 底部提示。
- 悬停场上/手牌任意卡即更新；未悬停时可保持上次内容（MTGA 同款常驻左栏）。

### 左上圆钮
- 设置（齿轮线条图标）+ 认输（心形线条图标），44px 圆钮。

## 11. 约束与不影响面

- 本轮全部为 **UI/表现层**改动：`GameRules`、`GameAction`、事件/效应模型、确定性回放、状态哈希**零改动**。
- 编辑器自动化可继续用 MCP For Unity 验证布局。
- 卡牌五色与插画不受主题重染（design-spec.md 既有约定）。
