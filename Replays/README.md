# 对局录像

每小局一个 `.mtgbr` 文件，默认名称为本地时间 `yyyy-MM-dd HH-mm-ss`，同名添加 ` (1)`、` (2)`，不覆盖已有录像。

在首页选择「观看录像」读取这里的文件。其他位置的录像可复制到本目录后点击刷新。录像记录双方视角的战场状态，不依赖重跑旧版规则引擎；卡图仍读取本机卡图目录。双方完整记录仅在该小局结束后传送。

「自动保存所有录像」位于设置中；关闭时每小局结束询问是否保存。异常中止的对局不生成完整录像。

导出的视频位于 `Videos`，格式为 1280×720、30 FPS、H.264 MP4（目前不含音轨）。导出使用当前选择的玩家视角，可用返回按钮取消；导出期间保持窗口尺寸不变。Unity 编辑器导出时需保持 Game 视图可见。

导出需要 FFmpeg：程序优先读取应用目录下 `VideoTools/ffmpeg.exe`，其次查找 PATH。播放器本身不需要 FFmpeg。
